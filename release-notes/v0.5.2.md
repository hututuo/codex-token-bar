# Codex Token Bar v0.5.2

这次更新主要修复未读会话提醒、账号额度回跳、登录项启动崩溃和启动/滚动阶段的可靠性问题，同时继续收口本地数据读取和发布安全检查。

## 更新亮点

- 修复未读会话提醒漏报：现在会更忠实地读取 Codex 的官方未读列表，不再因为 `has_user_event` 或暂未写入 SQLite 的会话而漏掉提醒，同时仍会过滤 subagent 和归档会话。
- 修复额度历史回跳：同一个重置周期内会忽略晚到的旧额度快照，避免 5h / 7d 剩余额度出现不合理的反向上升。
- 修复登录项启动崩溃：开机自启或后台启动时不再过早切换 AppKit 激活状态。
- 改进启动数据稳定性：快速统计已经显示后，即使后续精确扫描失败，也不会把主界面统计和 24h 图表清空。
- 修复悬浮窗多开残留：反复开关悬浮窗或出现多个主窗口实例时，会自动收口到唯一悬浮窗，并清理失联的旧面板，避免出现关不掉的第二、第三个悬浮窗。
- 降低悬浮窗锁定后的空闲开销：稳定跟随目标窗口后减少系统窗口枚举频率，降低常驻能耗。
- 收口本地数据层：统一 SQLite 访问、缓存读取、额度读取和 JSONL 解析的测试覆盖，减少后续统计口径漂移。
- 改进发布预检：继续保留 Sparkle 更新签名、DMG 背景检查、Hardened Runtime / Sandbox 发布门禁和权限说明检查。

## 更新说明

- 这仍然是本地优先版本：App 只读取本地 Codex 文件和 Codex 账户额度接口，不上传 prompt、输出、日志或额度历史。
- Sparkle 更新仍然需要用户确认，不会在后台静默替换 App。
- 当前构建仍是 ad-hoc 签名，尚未 Apple notarize。如果 macOS 提示“未知开发者”，请从官方 Release 下载并校验 SHA256 后再打开。

## English

This update focuses on unread session reminders, quota regression handling, launch-at-login stability, and startup/chart reliability, while tightening local data access and release checks.

## Highlights

- Fixes missed unread session reminders: the app now trusts Codex's official unread list more closely, no longer dropping reminders solely because `has_user_event` is false or a thread has not reached SQLite yet, while still filtering subagents and archived threads.
- Fixes quota history regressions: stale late-arriving quota snapshots are ignored within the same reset cycle, preventing 5h / 7d remaining quota from jumping upward incorrectly.
- Fixes a launch-at-login crash caused by switching the AppKit activation policy too early during startup.
- Improves startup data stability: once the fast snapshot is visible, a later precise scan failure no longer clears dashboard totals or recent charts.
- Fixes duplicate floating panel leftovers: repeated floating-panel toggles or multiple dashboard instances now converge to one active panel and clean up orphaned panels, preventing unclosable second or third floating windows.
- Lowers idle cost for locked floating panels by reducing system window enumeration once the target window is stable.
- Tightens the local data layer with unified SQLite access and broader tests for cache loading, quota reading, JSONL parsing, and realtime unread filtering.
- Improves release checks around Sparkle update signatures, styled DMG validation, Hardened Runtime / Sandbox gates, and permission descriptions.

## Update Notes

- Codex Token Bar remains local-first: it reads local Codex files and account quota APIs, and does not upload prompts, outputs, logs, or quota history.
- Sparkle updates still require user confirmation; the app does not silently replace itself in the background.
- The app remains ad-hoc signed and is not Apple notarized. Verify the SHA256 checksum before opening if macOS warns about an unidentified developer.
