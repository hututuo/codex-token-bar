# Codex Token Bar v0.8.4

v0.8.4 继续收敛 Swift 原生版与跨平台版的精确索引、增量刷新和聚合发布链路，重点是让旧版用户升级后继续复用索引，同时减少无变化刷新带来的等待和资源占用。

## 更新亮点

- **双端索引升级兼容**：从 v0.8.3 升级时保留原始会话和已发布事件，按受支持的迁移阶段补齐模型与推理字段；未知或更高版本索引会停止写入，避免覆盖未来数据。
- **增量扫描与恢复**：未变化文件继续复用字节级 checkpoint，追加文件只读取新增尾部；截断、替换和前缀变化只定向处理受影响文件，异常中断后可从已提交水位继续。
- **轻量摘要与图表聚合分离**：悬浮窗、状态栏和今日摘要使用轻量同步；24 小时、7 天、30 天图表、热力图和排行榜由独立聚合周期更新，并使用代数和 settled-through 保护缓存新旧关系。
- **更可靠的发布状态**：双端区分检查时间、摘要数据时间和图表覆盖时间，旧快照可以作为明确标记的 last-good 保留，不把未完成的模型统计伪装成默认模型。
- **跨平台顶部状态栏优化**：收敛目录、运行线程和状态指示器的布局，长路径和状态文案在有限宽度内保持可读。
- **兼容性与安全边界保持不变**：索引仍是可重建缓存，不保存会话正文，不上传本地用量；额度、Radar 和设置数据不因索引升级被删除。

## 更新说明

- 精确索引升级首次可能短暂占用 CPU 和磁盘；升级期间会显示进度，原始 Codex 会话不会被修改。
- macOS 构建采用 ad-hoc 签名且未经过 Apple notarization；Windows 安装器未使用商业代码签名证书，首次安装可能出现系统安全提示。
- 正式发布后请只从官方 GitHub Release 下载，并使用随包提供的 `SHA256SUMS-v0.8.4.txt` 核对文件。

## English

# Codex Token Bar v0.8.4

v0.8.4 continues converging the exact-index, incremental-refresh, and aggregate-publication paths across the native Swift and cross-platform editions. The focus is safe reuse for v0.8.3 users and lower cost for unchanged refreshes.

## Highlights

- **Compatible dual-platform index upgrades**: upgrading from v0.8.3 preserves original sessions and published events, then fills model and reasoning fields through supported migration stages. Unknown or newer index revisions fail closed instead of being overwritten.
- **Incremental scanning and recovery**: unchanged files reuse byte-level checkpoints and append-only files read only their new tails. Truncation, replacement, and prefix changes are handled per file, and interrupted work resumes from the last committed watermark.
- **Separate light summaries from chart aggregation**: the floating panel, status bar, and today summary use the lightweight lane. 24-hour, 7-day, 30-day charts, heatmaps, and rankings use an independent aggregate cadence with generation and settled-through cache guards.
- **More truthful publication status**: both editions distinguish check time, summary data time, and chart coverage time. A prior snapshot can remain visible as an explicitly stale last-good result instead of being replaced by a fabricated default model.
- **Refined cross-platform header**: the directory, running-thread, and status-indicator cells now share the available width while keeping long paths and status text readable.
- **Unchanged compatibility and privacy boundaries**: the index remains rebuildable cache data, does not store conversation text, and does not upload local usage. Quota, Radar, and settings data are not deleted by index upgrades.

## Update Notes

- The first exact-index upgrade may briefly use CPU and disk; progress is shown and original Codex sessions are never modified.
- The macOS build is ad-hoc signed and not Apple-notarized. Windows installers do not use a commercial code-signing certificate, so the operating system may show a first-install warning.
- After publication, download only from the official GitHub Release and verify the bundled `SHA256SUMS-v0.8.4.txt`.
