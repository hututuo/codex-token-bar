## 简体中文

- 修复 Windows 更新或覆盖安装时覆盖自定义快捷方式的问题，保留代理启动器、启动参数和工作目录。
- 修复 Windows 自启动路径修复时丢失已有启动参数的问题。
- macOS 与 Windows 同步兼容众测雷达新版 v6 数据，保留 v5 兼容和评分校验。
- 保留现有用量索引、历史统计与费用账本，无需重新导入。

若旧版更新已经覆盖代理快捷方式，请先恢复原有代理启动入口；本版本会保护后续更新，无法重建未知的旧启动脚本参数。

## English

- Preserve custom Windows shortcuts, proxy launchers, arguments and working directories during updates and reinstalls.
- Preserve existing arguments when repairing Windows startup registration.
- Support RadarBench v6 on macOS and Windows while retaining v5 compatibility and score validation.
- Keep existing usage indexes, historical statistics and cost ledgers without reimporting data.

If an earlier update already replaced a proxy shortcut, restore the original launch entry first. This update protects future updates but cannot reconstruct unknown previous launcher arguments.
