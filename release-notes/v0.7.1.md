# Codex Token Bar v0.7.1

这次更新是 Windows/Tauri 版的自动更新与托盘交互修复版。macOS Swift 版仍沿用 v0.7.0 资产和 Sparkle 更新通道；Windows 版从这一版开始接入 Tauri 自动更新。

## 更新亮点

- Windows 版新增内置自动更新：主界面可以检查 GitHub Release 中的 `latest-windows.json`，下载并安装已签名的 Windows 更新包。
- Windows 更新包现在包含 Tauri updater `.sig` 签名，使用独立的 Tauri 更新 key，不复用 macOS Sparkle key。
- 修复 Windows 托盘交互：左键打开主界面，右键显示菜单，并提供“打开主界面 / 退出”。
- 修复 Windows 重复启动会堆出多个托盘图标的问题：再次启动会尝试激活已有实例，不再无限创建新托盘入口。
- 修复悬浮窗双击行为：双击悬浮窗会打开主界面，而不是触发拖拽或居中。
- 修复 Windows 额度读取时偶发弹出黑色命令框的问题。
- 加强 Windows 发布脚本：构建失败会立即停止，签名 key 文件会正确注入 Tauri CLI，`latest-windows.json` 和 checksum 文件使用 UTF-8 无 BOM 输出。

## 更新说明

- Windows 自动更新只读取 Windows 专用 `latest-windows.json`；macOS 继续读取 Sparkle `appcast.xml`，两个更新通道不会混用。
- Windows 安装器仍未使用商业代码签名证书，首次运行可能出现 Microsoft Defender SmartScreen 未知发布者提示。请只从官方 GitHub Release 下载并校验 SHA256。
- 这次 GitHub Release 会继续放在统一版本列表里，方便同时找到 macOS 和 Windows 下载项；其中 macOS 资产沿用 v0.7.0，Windows 资产为 v0.7.1。

## English

This is a Windows/Tauri update and tray-interaction fix release. The macOS Swift build continues to use the v0.7.0 assets and Sparkle update lane; the Windows build now uses the Tauri updater.

## Highlights

- Adds built-in Windows updates: the dashboard can check `latest-windows.json` from GitHub Releases, download the signed Windows installer, and start the update flow.
- Windows update packages now include Tauri updater `.sig` signatures and use a dedicated Tauri updater key, separate from the macOS Sparkle key.
- Fixes Windows tray behavior: left click opens the dashboard, right click opens a menu with "Open Dashboard" and "Quit".
- Fixes duplicate tray icons when launching the app repeatedly: a second launch now activates the existing instance instead of creating another tray entry.
- Fixes floating-panel double click: double clicking the floating panel opens the dashboard instead of starting a drag or centering gesture.
- Fixes occasional black command windows during Windows quota reads.
- Hardens the Windows release script: failed commands now stop the build, key-file signing is correctly passed to the Tauri CLI, and `latest-windows.json` plus checksum files are written as UTF-8 without BOM.

## Update Notes

- Windows auto-update reads only the Windows-specific `latest-windows.json`; macOS continues to use the Sparkle `appcast.xml`. The two update lanes remain separate.
- Windows installers are still not signed with a commercial code-signing certificate. Microsoft Defender SmartScreen may warn about an unknown publisher on first launch. Download only from the official GitHub Release and verify SHA256.
- This GitHub Release stays in the unified version list so macOS and Windows downloads are easy to find together. The macOS assets remain at v0.7.0, while the Windows assets are v0.7.1.
