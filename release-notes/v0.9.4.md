# Codex Token Bar v0.9.4

## 简体中文

- 修复压缩聊天历史的读取与索引，普通 JSONL 和 JSONL.zst 共用来源身份，切换存储格式或同时存在两种文件时避免重复计数。
- 升级历史索引时保留已有消费记录和扫描断点；读取失败时保留可信历史数据，并提供有界扫描诊断。
- 减少排行摘录和消息链接补全对冷压缩历史的重复读取，必要的统计仍会验证正文。
- 加固 Windows 更新状态、安装器启动错误处理、安装路径和快捷方式检查，以及新进程对升级结果的确认。

Windows 旧版更新器的行为由旧版程序决定。如自动更新失败，请使用本版本的官方安装器安装到原目录，并核对启动后的版本。请保留本地历史数据。

## English

- Fixes compressed history reading and indexing. Plain JSONL and JSONL.zst share source identity to avoid duplicate counts when storage formats change or both representations exist.
- Preserves recorded usage and scan checkpoints during index upgrades, retaining trusted history and bounded diagnostics when reading fails.
- Reduces repeated reads of cold compressed history for ranking excerpts and message links while still validating content required for statistics.
- Hardens Windows update state, installer launch failure handling, installation paths, shortcuts, and upgrade confirmation by the new process.

The old Windows executable controls its own updater behavior. If automatic updating fails, use this version's official installer in the original directory and check the version after launch. Keep local history data.
