# Codex Token Bar v0.7.2

这次更新集中修复跨平台 / Tauri 版本的用量统计、额度读取、悬浮窗、24 小时图表、雷达和更新安全边界，让 Windows / Tauri 线更接近当前稳定目标态。

## 更新亮点

- 修复 fork / subagent 会话重放统计和旧缓存失效，避免总 token 被历史重放放大。
- 修复悬浮窗 `总 / 今 / 次` 的可信摘要口径，摘要重建时保留上一份可信数据，不再反复掉回“待读取”。
- 最近 24 小时图表改为可横向浏览 30 天内 5 分钟历史，并补充日期分隔和当前可见窗口日期范围。
- 缓存命中排行补齐“最新”候选和命中率色阶，低命中与最新排序都能看到正确条目。
- 额度读取加强了超时、噪声日志、旧成功数据保留、计划类型和历史记录口径；额度刷新频率可配置。
- 实时速率区分“准备中”和真实 stream 失败，避免准备状态误显示成降级/重试。
- Codex Radar 拆分公开摘要和主界面详细刷新，增加失败/陈旧状态诊断。
- Provider 修复入口改为明确的高级手动流程，并增加操作守卫和一次性安全扫描。
- Tauri 窗口能力权限和敏感命令边界进一步收紧。

## 更新说明

- 本说明对应 Windows / Tauri 更新线。macOS / Swift 资产、Sparkle appcast 和发布节奏由 macOS 线单独准备，不在本批 Tauri 更新包中重建。
- Windows / Tauri 自动更新继续使用 `latest-windows.json` 和 Tauri updater `.sig`，不与 macOS Sparkle appcast 混用。
- Windows 安装器仍未使用商业代码签名证书，首次运行可能出现未知发布者提示；请只从官方 GitHub Release 下载并校验 SHA256。

## English

This update focuses on the cross-platform / Tauri build: usage totals, quota reads, floating panel behavior, the 24-hour chart, Radar diagnostics, and update/security boundaries.

## Highlights

- Fixes fork/subagent replay accounting and invalidates stale usage caches that could inflate total tokens.
- Keeps trusted `total / today / requests` compact usage metrics stable while precise summaries rebuild.
- Makes the 24-hour chart horizontally browseable across 30 days of 5-minute history, with day markers and a visible-window date range.
- Improves cache-hit ranking with real latest candidates and Swift-aligned hit-rate tones.
- Hardens quota reads, timeout/noisy-log handling, stale-success preservation, account plan handling, and quota history; adds configurable quota refresh cadence.
- Separates live-rate preparation from real stream failures, avoiding false degraded/retry states.
- Splits Codex Radar public summary from dashboard full-detail refresh and adds stale/failure diagnostics.
- Mounts Provider Repair as an explicit advanced manual flow with operation guards and one-shot safe scanning.
- Tightens Tauri window capabilities and sensitive command boundaries.

## Update Notes

- These notes are for the Windows / Tauri update lane. macOS / Swift assets, Sparkle appcast metadata, and release cadence are prepared separately by the macOS lane and are not rebuilt by this Tauri update package.
- Windows / Tauri updates continue to use `latest-windows.json` and Tauri updater `.sig` files, separate from the macOS Sparkle appcast.
- Windows installers are still not signed with a commercial code-signing certificate. SmartScreen may warn about an unknown publisher; download only from the official GitHub Release and verify SHA256.
