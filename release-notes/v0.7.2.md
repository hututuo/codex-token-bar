# Codex Token Bar v0.7.2

这次是 Mac Swift 版的稳定性更新，重点修正本地统计口径、实时速率、雷达详情刷新、曲线图浏览和额度刷新设置。Windows / Tauri 版本继续走自己的更新路线，不共用 Mac appcast。

## 更新亮点

- 修复 fork 会话重复统计：分支会话开头复制出来的历史 token 不再被重复算进总量，fork 后新的真实调用仍会正常计入。
- 稳定 `总 / 今 / 次` 指标：准备精确 token 缓存或只能读取元数据时，不再用临时数据冒充精确统计，也不会清掉上一份可信结果。
- 曲线图支持横向浏览历史：24h、7d、30d 都可以保持原来的显示区域，通过滚动和左右按钮查看更久之前的数据；30d 可用更细颗粒度浏览。
- 新增额度刷新频率设置：可在 30 秒、1 分钟、3 分钟、5 分钟、10 分钟之间选择，主界面和悬浮窗共用同一个设置。
- 雷达接入公开摘要和详情刷新：基础/悬浮显示继续使用公开 `current.json`，详情数据按本地 08:00 / 18:00 定时刷新，并避免失败后同一时段反复自动重试。
- 实时速率继续修正：切换 Codex Home 时会重置来源状态，坏日志或无效时间戳不会制造虚假尖峰，显示保持一位小数。
- 增加未读会话一键已读：状态栏和相关入口可以更方便地处理未读会话提醒。
- 强化 Provider 同步和额度历史的过期回写保护，减少后台任务慢完成时覆盖新状态的风险。
- 兼容新版 ChatGPT 内置 Codex CLI：额度读取会依次尝试显式路径、LaunchServices、系统/用户 Applications、PATH 与 Homebrew，不再依赖固定 App 名称或单一安装位置。
- 收紧 Codex App 身份校验：自动发现只接受正确的 `com.openai.codex` App，避免误用其他软件附带的同名可执行文件；Provider 同步也能识别改名后的 ChatGPT/Codex 进程。

## 更新说明

- Mac 版仍使用原生 Swift App、DMG 安装包和 Sparkle appcast；Windows 版请使用 Windows 对应资产。
- 实时速率仍然只是工作强度估计，不代表精确真实吞吐。
- 本地 token、缓存命中、会话统计、额度历史、重置卡和雷达信息不会上传到第三方。
- 当前构建仍是 ad-hoc 签名，尚未 Apple notarize。如果 macOS 提示“未知开发者”，请从官方 Release 下载并校验 SHA256 后再打开。

## English

This is a stability update for the native Mac Swift build. It focuses on local usage accounting, live-rate behavior, Radar detail refresh, chart browsing, and quota refresh cadence. The Windows / Tauri build continues to use its own update lane and must not use the Mac appcast.

## Highlights

- Fixes duplicated fork-session usage: replayed history at the beginning of a forked session is no longer counted again, while real calls after the fork still count normally.
- Stabilizes total / today / current-call metrics: precise-cache preparation and metadata-only states no longer masquerade as trusted totals or clear the last trusted result.
- Adds horizontally scrollable history charts: 24h, 7d, and 30d charts keep the original viewport size while scroll buttons and trackpad scrolling reveal older history; 30d can be viewed with finer granularity.
- Adds quota refresh cadence settings: choose 30 seconds, 1 minute, 3 minutes, 5 minutes, or 10 minutes. Dashboard and floating panel share the same setting.
- Improves Codex Radar loading: compact/basic surfaces keep using the public `current.json`, while full detail refreshes on the local 08:00 / 18:00 schedule and avoids repeated automatic retries for the same failed slot.
- Refines live-rate behavior: switching Codex Home resets source-local live-rate state, malformed timestamps no longer create fake spikes, and displayed values keep one decimal.
- Adds one-click mark-read support for unread session reminders.
- Hardens Provider sync and quota-history state publishing so slower background work is less likely to overwrite newer state.
- Supports the Codex CLI bundled with the renamed ChatGPT app: quota reading now checks an explicit override, LaunchServices, system/user Applications, PATH, and Homebrew instead of relying on a fixed app name or install location.
- Tightens Codex app identity checks: automatic discovery accepts only the expected `com.openai.codex` app, avoiding unrelated bundled executables with the same filename, while Provider sync recognizes the renamed ChatGPT/Codex process.

## Notes

- The Mac build still uses the native Swift app, DMG installer, and Sparkle appcast updates. Use the Windows assets for Windows.
- Live rate remains a work-intensity estimate, not exact throughput.
- Local token usage, cache hit rates, session statistics, quota history, reset-credit data, and Radar data are not uploaded to third parties.
- The app remains ad-hoc signed and is not Apple notarized. Verify the SHA256 checksum before opening if macOS warns about an unidentified developer.
