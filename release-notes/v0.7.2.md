# Codex Token Bar v0.7.2

这是 Codex Token Bar 的双平台稳定性更新。Mac 继续使用原生 Swift App，Windows 继续使用 Tauri + React + Rust App；两个平台共用一个 `v0.7.2` GitHub Release，但各自使用独立的安装包和更新通道。

## Mac / Swift 更新亮点

- 修复 fork 会话重复统计：分支会话开头复制出来的历史 token 不再被重复算进总量，fork 后的新调用仍会正常计入。
- 稳定 `总 / 今 / 次` 指标：准备精确 token 缓存或只能读取元数据时，不再用临时数据冒充精确统计，也不会清掉上一份可信结果。
- 曲线图支持横向浏览历史：24h、7d、30d 保持固定显示区域，通过滚动和左右按钮查看更早数据；30d 支持更细颗粒度。
- 新增额度刷新频率设置：可选 30 秒、1 分钟、3 分钟、5 分钟、10 分钟，主界面和悬浮窗共用同一个设置。
- 雷达基础显示继续使用公开摘要，详情按本地 08:00 / 18:00 刷新，并避免失败后在同一时段反复自动重试。
- 修正实时速率来源切换、异常日志和时间戳处理，补充未读会话一键已读，并强化 Provider 同步与额度历史的过期回写保护。

## Windows / Tauri 更新亮点

- 修复 fork / subagent 重放统计和旧缓存失效，避免历史重放放大总 token。
- 稳定悬浮窗 `总 / 今 / 次` 的可信摘要：正常会话增量更新期间保留同源可信结果，且 live-rate 不再每秒扫描全部会话文件。
- 最近 24 小时图表可横向浏览 30 天内的 5 分钟历史，并显示日期分隔和当前可见窗口日期范围。
- 缓存命中排行补齐“最新”候选和命中率色阶；额度读取加强超时、噪声日志、旧成功数据保留、计划类型和历史记录口径。
- 实时速率明确区分缓存准备和真实 stream 失败；Codex Radar 增加公开摘要、详情刷新和陈旧/失败诊断。
- Provider 修复作为高级手动流程提供操作守卫和一次性安全扫描；Tauri 窗口能力及敏感命令边界进一步收紧。

## 两个平台共同改进

- 兼容 Codex Desktop / ChatGPT App 更名、移动和自定义安装位置：额度读取支持显式路径、LaunchServices、系统/用户 Applications、Homebrew 和 PATH 回退。
- 自动发现的 App bundle 必须匹配 `com.openai.codex`，避免误用其他软件附带的同名可执行文件。
- Codex Desktop 侧栏补丁脚本也改用 App 自动发现和 bundle identity 校验，不再依赖固定 App 名称。

## 发布说明

- Mac v0.7.2 资产版本为 `0.7.2`、build `702`，继续使用 Sparkle appcast；当前为 ad-hoc 签名且未 Apple notarize。
- 本次 Release 包含 Windows x64 与 Windows ARM64 两套 NSIS 安装器，并附带各自的 Tauri updater 签名和统一 SHA256 校验文件。
- Mac 和 Windows 文件放在同一个 `v0.7.2` GitHub Release；Mac 使用 Sparkle，Windows 使用独立的 Tauri updater metadata，两个更新通道不会混用。
- Windows 安装器仍未使用商业代码签名证书，首次运行可能出现未知发布者提示。
- 实时速率只是工作强度估计，不代表精确吞吐。本地 token、缓存命中、会话统计、额度历史、重置卡和雷达信息不会作为遥测上传。

## English

This is a cross-platform stability release for Codex Token Bar. Mac continues to use the native Swift app, while Windows uses the Tauri + React + Rust app. Both platforms share one `v0.7.2` GitHub Release, with separate installers and update channels.

## Mac / Swift Highlights

- Fixes duplicated fork-session accounting so replayed history is not counted again, while real calls after the fork still count normally.
- Stabilizes total / today / current-call metrics: cache preparation and metadata-only states no longer masquerade as trusted totals or clear the last trusted result.
- Adds horizontally browseable 24h, 7d, and 30d history while keeping a stable viewport; 30d supports finer granularity.
- Adds shared quota refresh cadence options for 30 seconds, 1 minute, 3 minutes, 5 minutes, and 10 minutes.
- Keeps basic Radar on the public summary, schedules detail refreshes at local 08:00 / 18:00, and prevents repeated automatic retries for the same failed slot.
- Refines live-rate source switching, malformed log/timestamp handling, one-click unread acknowledgement, Provider sync stale-publish protection, and quota-history safety.

## Windows / Tauri Highlights

- Fixes fork/subagent replay accounting and invalidates stale caches that could inflate total tokens.
- Keeps trusted compact total / today / requests values during ordinary session appends and removes per-tick full session-tree scans from live rate.
- Makes the 24-hour chart horizontally browseable across 30 days of 5-minute history, with day separators and a visible-window date range.
- Improves cache-hit ranking with real latest candidates and hit-rate tones, and hardens quota timeouts, noisy logs, stale-success retention, plan labels, and history.
- Separates cache preparation from real live-stream failures and adds public/detail Radar refresh plus stale/failure diagnostics.
- Keeps Provider Repair as a guarded advanced manual flow and tightens Tauri window capabilities and sensitive-command boundaries.

## Shared Improvements

- Supports renamed, moved, and custom Codex Desktop / ChatGPT App installations through explicit overrides, LaunchServices, system/user Applications, Homebrew, and PATH fallbacks.
- Requires discovered app bundles to match `com.openai.codex`, avoiding unrelated bundled executables with the same filename.
- Updates the Codex Desktop sidebar patch helper to use App discovery and bundle-identity validation instead of fixed App names.

## Release Notes

- The Mac v0.7.2 assets use version `0.7.2`, build `702`, and Sparkle. The app remains ad-hoc signed and is not Apple notarized.
- This Release includes separate Windows x64 and Windows ARM64 NSIS installers, their Tauri updater signatures, and a unified SHA256 checksum file.
- Mac and Windows files share the same `v0.7.2` GitHub Release. Mac uses Sparkle; Windows uses separate Tauri updater metadata. The update channels are not interchangeable.
- Windows installers are not signed with a commercial code-signing certificate, so SmartScreen may warn about an unknown publisher.
- Live rate remains a work-intensity estimate, not exact throughput. Local token usage, cache hit rates, session statistics, quota history, reset-credit data, and Radar data are not uploaded as telemetry.
