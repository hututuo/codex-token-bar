# v0.9.2 — 候选，尚未正式发布

新增独立额度侧栏；新安装默认启用额度侧栏，升级保留已有浮窗和状态栏显式设置。修复窗口恢复、引导布局及源文件替换漏检，稳定刷新继续使用轻量元数据检查。历史无报价记录明确显示未定价。

修复价格未知提示的显示范围：单个模型缺少报价时，仅该模型显示“价格未知”，其他模型的费用仍然显示，并标记为“已知价格小计”；全部计费用量均无报价时显示“—”，避免误报为零费用。

本版本仍为候选版本。较旧程序不保证能读取已升级的精确索引，降级前请保留数据备份，不要删除永久账本。

## English

Adds a separate quota sidebar, enabled by default for new installations. Upgrades preserve explicit floating-window and menu-bar preferences. Fixes window restoration, onboarding layout, and missed source-file replacements while keeping steady-state refreshes lightweight. Historical usage without a quoted price remains visibly unpriced.

Limits unknown-price messages to the affected model. Other model costs remain visible as a known-price subtotal. When all billable usage is unpriced, the cost shows “—” instead of an incorrect zero.

This is a release candidate. Older versions may not read an upgraded exact-usage index. Preserve a data backup before downgrading and do not delete the permanent ledger.
