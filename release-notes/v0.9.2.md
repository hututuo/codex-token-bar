# v0.9.2

新增独立额度侧栏；新安装默认启用额度侧栏，升级保留已有浮窗和状态栏显式设置。修复窗口恢复、引导布局及源文件替换漏检，稳定刷新继续使用轻量元数据检查。历史无报价记录明确显示未定价。

修复价格未知提示的显示范围：单个模型缺少报价时，仅该模型显示“价格未知”，其他模型的费用仍然显示，并标记为“已知价格小计”；全部计费用量均无报价时显示“—”，避免误报为零费用。

额度侧栏的 5h 与 7d 圆环内增加本地重置日期和时间；众测推荐每页显示三项，每四秒自动翻页，悬停或键盘聚焦时暂停。

缓存命中偏低时，一级侧栏显示提示并展开二级菜单；提醒优先展示正式会话名称，不把首条提问当成标题，仍可进入详细菜单查看。新建会话和上下文压缩后的首个请求不触发低命中提醒，review 会话也不参与提醒。关闭同一次提醒后不重复弹出，提醒开关继续生效。

速率条满格值在首次运行本版时统一初始化为 150 tok/s，包括升级前保存过其他数值的用户；之后的手动调整仍按本地设置保存。Swift 与跨平台/Windows 端一致，可调范围为 50–500 tok/s。修复 Windows 额度侧栏展开时的原生裁切，使圆环正常显示。

较旧程序不保证能读取已升级的精确索引，降级前请保留数据备份，不要删除永久账本。

## English

Adds a separate quota sidebar, enabled by default for new installations. Upgrades preserve explicit floating-window and menu-bar preferences. Fixes window restoration, onboarding layout, and missed source-file replacements while keeping steady-state refreshes lightweight. Historical usage without a quoted price remains visibly unpriced.

Limits unknown-price messages to the affected model. Other model costs remain visible as a known-price subtotal. When all billable usage is unpriced, the cost shows “—” instead of an incorrect zero.

The 5h and 7d quota rings now show their local reset date and time. Community recommendations show three entries per page, advancing every four seconds and pausing on hover or keyboard focus.

Low cache-hit reminders now appear on the collapsed sidebar and expand its summary. Notices prefer the explicit session name rather than treating the first prompt as a title, with details still available in the full menu. The first request in a new or compacted session and guardian review sessions do not trigger low-hit reminders. Dismissing a request prevents repeat alerts for that request, and the reminder setting remains respected.

On first launch of this version, the rate-bar full scale is initialized to 150 tok/s, including for users with a previously saved value. Later manual changes remain saved locally. Swift and cross-platform/Windows builds share this behavior and a 50–500 tok/s range. Fixes native clipping when the Windows quota sidebar expands so quota rings remain visible.

Older versions may not read an upgraded exact-usage index. Preserve a data backup before downgrading and do not delete the permanent ledger.
