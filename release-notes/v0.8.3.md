# Codex Token Bar v0.8.3

v0.8.3 继续优化完整、本地、精确的历史统计：不以文件数量、字节数、事件数或扫描时长上限换取性能。

## 更新亮点

- **更平稳的实时刷新**：实时速率更新不再反复重绘 Swift 历史用量曲线，减少主窗口在活跃使用时的无效工作。
- **更快的跨平台历史聚合**：Tauri 版复用精确历史聚合快照，避免在同一次读取中重复构建曲线、排行和摘要。
- **更可靠的数据源切换**：切换不同 Codex 数据目录时，精确索引暂存严格按数据源隔离；闲置操作锁会及时释放。
- **完整历史仍然精确**：精确索引持续覆盖所有可读取的本地历史，并支持断点续扫、增量更新和安全重建。

## 更新说明

- 这是兼容现有精确索引格式的维护版本；已有索引会继续复用，不会因为升级而无故全量重扫。
- 精确索引是本地缓存，不保存会话正文，也不会上传本地用量、历史或索引数据。
- macOS 构建采用 ad-hoc 签名且未 Apple notarize；Windows 安装器未使用商业代码签名证书。请只从官方 Release 下载并核对 SHA256。

## English

# Codex Token Bar v0.8.3

v0.8.3 continues to improve complete, local, exact history accounting without trading file-count, byte, event, or scan-time caps for performance.

## Highlights

- **Smoother live refreshes**: live-rate updates no longer repeatedly redraw the Swift history chart, reducing unnecessary work in the main window during active use.
- **Faster cross-platform aggregation**: the Tauri app reuses exact-history aggregate snapshots instead of rebuilding charts, rankings, and summaries within the same read.
- **More reliable source switching**: temporary exact-index state is isolated by Codex data source, and inactive operation locks are released promptly.
- **Full history remains exact**: the exact index keeps all readable local history in scope and supports resumable scans, incremental updates, and safe rebuilds.

## Update Notes

- This maintenance release is compatible with the existing exact-index format. Existing indexes are reused and an upgrade does not trigger an unnecessary full scan.
- The exact index is local cache data: it does not retain conversation text or upload local usage, history, or index data.
- The macOS build is ad-hoc signed and not Apple notarized. Windows installers do not use a commercial code-signing certificate. Download only from the official Release and verify SHA256.
