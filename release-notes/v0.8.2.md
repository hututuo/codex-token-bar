# Codex Token Bar v0.8.2

v0.8.2 重做了 macOS Swift 原生版和 Windows Tauri 版的本地精确历史统计。目标不是限制可读取的历史，而是在保留完整、精确结果的前提下，让大体量 Codex 历史能够持续复用索引、增量更新并快速恢复。

## 主要更新

- **无限历史的精确索引**：历史统计改用可重建的本地 SQLite 外存索引，不再用文件数、字节数、事件数或扫描时长上限换取性能。只要原始 Codex JSONL 仍在，统计就覆盖全部可读取历史。
- **字节级增量续扫**：记录每个源文件已经确认处理到的字节位置。文件只在尾部增长时，从上次结束位置继续解析；文件被截断、替换或中段改变时，会安全重建受影响部分。
- **更快的首次建库**：Swift 与 Tauri 都会并行准备历史分片；Tauri 使用一个重任务配合多个轻任务工作线程，并通过 SQLite 批量事务导入，显著降低大型历史首次索引的等待时间。
- **稳定复用已有索引**：同一索引格式下，软件更新、重启和日常刷新都会继续使用现有精确索引，不会因为重新构建 App 而无故全量重扫。
- **更轻的活动刷新**：稳定历史直接复用已聚合快照，只有真正变化的会话进入增量解析。活跃使用期间的精确历史刷新由分钟级降到数秒级。
- **断点恢复**：Tauri 的建库过程使用可恢复代次和暂存状态。异常退出或系统中断后，可从已确认进度继续，而不是丢弃所有工作。
- **隐私边界不变**：索引只保存统计所需的数值、时间、文件身份和源偏移，不保存会话正文，也不上传本地用量、历史或索引数据。
- **雷达测试隔离**：Dashboard 运行时测试不再访问真实 Radar 网络，减少测试噪声和外部服务依赖。

## 升级说明

- 从 v0.8.0 首次升级到 v0.8.2 时，因为 v0.8.0 没有这套精确 SQLite 索引，需要完成一次初始建库；之后同格式版本会直接复用。
- 精确索引是缓存，不是数据源。删除索引不会删除 Codex 会话，只会在下次统计时重新建立。
- macOS 构建采用 ad-hoc 签名且未 Apple notarize；Windows 安装器未使用商业代码签名证书。请只从官方 Release 下载并核对 SHA256，系统可能显示未知开发者或未知发布者提示。

## English

# Codex Token Bar v0.8.2

v0.8.2 rebuilds exact local history accounting for both the native macOS Swift app and the Windows Tauri app. It improves performance without limiting readable history: complete results are retained while large Codex histories become incrementally indexed, resumable, and reusable across launches.

## Highlights

- **Exact indexing without history caps**: usage history now uses a rebuildable local SQLite index. Performance no longer depends on file-count, byte, event, or scan-time limits; all readable source history remains in scope.
- **Byte-level incremental scanning**: the index records the confirmed source offset for every file. Append-only growth resumes from the previous endpoint, while truncation, replacement, or earlier-file changes safely rebuild the affected data.
- **Faster first index**: Swift and Tauri prepare history shards in parallel. Tauri combines one heavy worker with several light workers and imports through batched SQLite transactions to reduce first-index time on large histories.
- **Persistent index reuse**: app updates, relaunches, and routine refreshes reuse the existing exact index when its format remains compatible. Rebuilding the app does not trigger an unnecessary full scan.
- **Lighter active refreshes**: stable history reuses aggregated snapshots and only changed conversations enter incremental parsing. Exact refreshes during active use drop from minutes to seconds on the tested large local history.
- **Resumable construction**: Tauri keeps recoverable generations and staging state. An interruption can continue from confirmed progress instead of discarding the complete build.
- **Unchanged privacy boundary**: the index stores only numeric statistics, timestamps, file identity, and source offsets required for accounting. It does not store conversation text or upload local usage, history, or index data.
- **Isolated Radar tests**: Dashboard runtime tests no longer access the live Radar network, reducing external dependency and test noise.

## Upgrade notes

- The first upgrade from v0.8.0 to v0.8.2 performs a one-time initial index build because v0.8.0 did not contain this exact SQLite index. Later compatible releases reuse it.
- The exact index is a cache, not the source of truth. Deleting it does not delete Codex conversations; it only causes the index to be rebuilt.
- The macOS build is ad-hoc signed and not Apple-notarized. Windows installers do not use a commercial code-signing certificate. Download only from the official Release and verify SHA256; the operating system may show an unidentified-developer or unknown-publisher warning.
