# Codex Token Bar v0.9.5

## 简体中文

- 新增本机缓存续问图表：用颜色深浅显示轮次密度，合并展示推荐续问线与最晚参考线；支持按模型、最近 7 天、最近 30 天或全部历史查看。
- 主页和低缓存命中提醒共用图表入口；提醒会显示本轮实际间隔与本机历史建议。0–80 分钟按每 10 分钟一格展开，更长间隔在末尾压缩显示。
- 改善续问建议的稳定性：拟合质量相近时选择下降更明显的位置，减少少量新数据引起的大幅跳动。
- 保留会话归档、移动或删除前已记录的用量与续问样本；同一路径日志改写时保留旧代记录，fork 后新增轮次继续统计。
- 同一会话 UUID 的完全相同用量副本使用可逆去重，保留原始事件；不同 UUID 或不一致记录不会误合并。索引发布、汇总、去重和扫描证明保持一致，失败时保留上一份可信数据。
- 更新公共众测雷达数据展示；macOS 另外修复了额度观测刷新、周期归因不确定性、部分已知价格费用小计和图表交互。

图表仅根据本机可验证的历史估计，不保证服务端缓存有效期。Windows 自动更新失败时，请使用本版本官方安装器安装到原目录，并保留历史数据。

## English

- Adds a local cache follow-up chart with density shading, a recommended follow-up line, a latest-reference line, and model and date filters.
- Shares one chart between the dashboard and low-cache-hit reminders. Reminders show the observed idle interval and local recommendation. The first 80 minutes use a linear ten-minute scale; longer gaps are compressed at the far end.
- Stabilizes recommendations by preferring the larger decline among similarly supported fits, reducing abrupt changes after a small number of new samples.
- Retains recorded usage and diagnostic samples when sessions are archived, moved, or deleted. Log rewrites retain earlier generations, and new rounds after a fork remain counted.
- Reversibly excludes identical usage copies within the same session UUID while retaining physical events. Different UUIDs and conflicting records stay separate. Index publication keeps totals, deduplication, and scan evidence consistent and preserves the last trusted state on failure.
- Updates public benchmark presentation. macOS also improves quota observation refresh, uncertain cycle attribution, partial known-price subtotals, and chart interaction.

Recommendations reflect verifiable local history and do not guarantee server-side cache lifetime. If Windows automatic updating fails, use this version's official installer in the original directory and retain local history data.
