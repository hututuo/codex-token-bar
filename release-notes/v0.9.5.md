# Codex Token Bar v0.9.5

## 简体中文

- 新增正文测速：按本地消息记录的起止时间与正文分词量计算 TPS，区分中间消息和最终文本，展示会话、时间、模型及样本可信度。短时或异常样本可查看，但不计入模型均速。
- 主页展示最近 6 条已识别模型的测速记录，详情面板支持查看历史；额度侧栏展示各模型最近速度，展开面板同时显示最新、15 分钟和 30 分钟速度。
- 更新全会话活动曲线：中断时及时停止，正常结束最多收尾 5 秒。活动曲线是显示估算，与正文 TPS 分开呈现。
- 归档、移动或删除原会话文件后，保留已记录的历史用量；失效会话路径不再阻断其他正常来源的统计。fork 后新增轮次继续统计，重复 UUID 的相同用量副本可逆去重。
- 移除低缓存命中提醒和续问时间建议；缓存命中统计、排行、费用账本及已有历史数据继续保留。
- 更新公共众测雷达展示；macOS 改善额度观测刷新、周期归因、已知模型费用小计和图表交互。

正文 TPS 来自本地可验证的消息时间和 `o200k_base` 分词估算，并非服务端纯推理速度；隐藏思考和工具返回不计入正文测速。网络等待可能影响结果。macOS 为 ad-hoc 签名，未经过 Apple 公证；请从官方发布页下载安装包。Windows 自动更新失败时，可使用官方安装器安装到原目录并保留历史数据。

## English

- Adds body-text TPS from local message start/end times and tokenized text, separating intermediate messages from final text. Samples show the conversation, time, model and confidence. Short or anomalous samples remain inspectable but are excluded from model averages.
- Shows the six latest model-identified samples on the dashboard, with history in a details panel. The quota sidebar shows recent model speeds; its expanded panel includes latest, 15-minute and 30-minute speeds.
- Updates the all-session activity curve: interruptions stop it promptly, and normal completion finishes within five seconds. This display estimate is shown separately from body-text TPS.
- Preserves recorded usage after session files are archived, moved or deleted. Missing rollout references no longer block other valid sources. Fork-owned new rounds remain counted, and identical usage copies within one UUID are reversibly deduplicated.
- Removes low-cache-hit reminders and follow-up timing recommendations while retaining cache-hit statistics, rankings, the cost ledger and existing history.
- Updates public benchmark presentation. macOS also improves quota refresh, cycle attribution, known-price subtotals and chart interaction.

Body-text TPS uses verifiable local message timing and estimated `o200k_base` token counts; it is not pure server-generation throughput. Hidden reasoning and tool-return text are excluded. Network waits can affect results. The macOS build is ad-hoc signed and is not Apple notarized; download installers from the official release page. If Windows automatic updating fails, use the official installer in the original directory and retain local history.
