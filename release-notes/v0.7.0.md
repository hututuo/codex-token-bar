# Codex Token Bar v0.7.0

这次更新把 Mac 版继续稳定在原生 Swift 路线：重点改进了实时速率显示、用量统计刷新性能、额度反推工具、重置卡详情和悬浮窗细节。Windows 版同样使用 `0.7.0` 版本号，但会按 Windows 自己的构建与更新路线发布。

## 更新亮点

- 用量统计改为增量刷新：手动刷新和自动刷新仍然是真刷新，但只处理新增或变化的会话文件，减少大体量历史数据下的重复扫描和缓存重写。
- 实时速率更像“工作强度估计”：速度显示加入轻量平滑、显示上限和工具输入估算，降低 300-500 tok/s 这类离谱跳值；主界面也明确说明该速率只是估算。
- 可以关闭实时速率：不想看速率的人可以直接关闭，主界面会变暗提示，悬浮窗里的速率模块也会同步关闭或开启。
- 速度条更省性能：速度条填充改为 layer-backed 渲染，保留平滑过渡，但避免 SwiftUI Shape 动画持续占用 CPU。
- 新增额度反推工具：在最近 24 小时曲线上选择起止范围后，可以根据 token 用量、缓存命中率、官方 API 定价和额度下降反推 5h / 7d 的估计总额度。
- 额度曲线更稳：读取额度历史时会过滤明显异常的瞬间 100 / 0 跳点，并在中间缺失记录时平滑连接正常下降段。
- 重置卡详情更清楚：主界面显示最近一张卡还剩多久，详情列表按最近到期排序，默认收起，只保留头像、剩余时间和进度条，点击后展开原因、关联用户、到期时间和卡片编号。
- 悬浮窗继续打磨：趣味化余量、雷达、额度条、总/今/次调用的排版和自适应文字颜色继续调整，速率条上和居中状态使用不同字号。

## 更新说明

- Mac 版仍使用 Swift 原生 App、DMG 安装包和 Sparkle appcast 更新；Windows 版请使用 Windows 对应资产，不要混用 Mac 的 appcast。
- 速率显示只用于判断 Codex 是否正在工作，不代表精确真实吞吐。官方为避免高频日志写入损耗硬盘，已经砍掉了很多流式输出日志。
- 额度反推是估算工具，7d 下降太少、记录颗粒度太粗或遇到异常额度点时，结果可能偏差较大；界面会显示 7d / 5h 倍率辅助判断可信度。
- 本地 token、缓存命中、会话统计、额度历史和重置卡信息仍然来自本机 Codex 数据与本地账号接口。
- Codex Token Bar 不会上传 prompt、输出、日志、会话内容或账号额度。
- Sparkle 更新仍然需要用户确认，不会在后台静默替换 App。
- 当前构建仍是 ad-hoc 签名，尚未 Apple notarize。如果 macOS 提示“未知开发者”，请从官方 Release 下载并校验 SHA256 后再打开。

## English

This update keeps the Mac build on the native Swift lane. It focuses on live-rate display stability, incremental usage refresh performance, quota estimation, reset-credit details, and floating-panel polish. The Windows build also uses version `0.7.0`, but it should be released through the Windows-specific build and update path.

## Highlights

- Makes usage refresh incremental: manual and automatic refreshes still perform real refreshes, but only new or changed session files are processed, reducing repeated scans and large cache rewrites.
- Makes live rate feel more like a work-intensity estimate: lightweight smoothing, display caps, and tool-input estimation reduce unrealistic 300-500 tok/s spikes, and the dashboard now explains that the rate is only an estimate.
- Adds a live-rate off switch: users who do not want live rate can disable it. The dashboard dims the rate area, and the floating-panel rate module follows the same setting.
- Improves speed-bar performance: the speed fill is now layer-backed, keeping smooth visual transitions while avoiding continuous SwiftUI Shape animation CPU cost.
- Adds quota back-estimation: select a range on the recent 24-hour chart to estimate 5h / 7d total quota from token usage, cache hit rate, official API pricing, and quota drops.
- Stabilizes quota curves: obvious instant 100 / 0 anomaly points are filtered, and normal drops are connected smoothly across missing history gaps.
- Clarifies reset-credit details: the dashboard shows the nearest expiring credit, the detail list is sorted by expiry, rows stay collapsed by default, and each row can expand to show reason, linked user, expiry time, and card ID.
- Polishes the floating panel: playful quota hints, Radar data, quota bars, and total/today/current calls receive further layout and adaptive text-color tuning, with separate font sizes for embedded and centered hint styles.

## Update Notes

- The Mac build still uses the native Swift app, DMG installer, and Sparkle appcast updates. Use the Windows assets for Windows; do not mix the Mac appcast into the Windows update lane.
- Live rate is only a rough signal that Codex is working, not an exact throughput measurement. Official Codex builds now suppress many high-frequency streaming logs to avoid excessive disk writes.
- Quota back-estimation is approximate. If the 7d quota barely moves, history granularity is coarse, or anomalous quota points appear, the result may drift; the UI shows the 7d / 5h ratio as a confidence hint.
- Local token usage, cache hit rates, session statistics, quota history, and reset-credit data still come from local Codex files and local account endpoints.
- Codex Token Bar does not upload prompts, outputs, logs, conversation content, or quota data.
- Sparkle updates still require user confirmation; the app does not silently replace itself in the background.
- The app remains ad-hoc signed and is not Apple notarized. Verify the SHA256 checksum before opening if macOS warns about an unidentified developer.
