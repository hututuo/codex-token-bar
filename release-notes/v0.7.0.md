# Codex Token Bar v0.7.0

这次更新把 Codex Token Bar 推进到双平台发布：macOS 继续使用原生 Swift 版，Windows 首次提供 Tauri + React + Rust 版，并在同一个 GitHub Release 里提供 macOS DMG、Windows x64 和 Windows ARM64 安装包。

## 更新亮点

- 新增 Windows 版本：提供 `windows-x64` 和 `windows-arm64` 两个 NSIS 安装包。
- macOS 版继续走 Swift 原生路线：保留 DMG 安装包和 Sparkle 自动检查更新。
- 用量统计改为增量刷新：手动刷新和自动刷新仍然是真刷新，但尽量只处理新增或变化的会话文件，降低大历史库下的重复扫描和缓存重写。
- 实时速率更像“工作强度估计”：速度显示加入轻量平滑、显示上限和工具输入估算，降低离谱跳值；工具输出和 patch 结果不会制造虚高 tok/s。
- 可以关闭实时速率：主界面会显示关闭态，悬浮窗里的“速率 + 速率条”模块也会同步隐藏或恢复。
- Windows 悬浮窗可用：支持实时速率、总/今/次统计、5h / 7d 额度、重置卡数量、模型 IQ 和趣味节奏提示。
- 新增额度反推工具：在最近 24 小时曲线上选择范围后，可以根据 token 用量、缓存命中率、官方 API 定价和额度下降反推 5h / 7d 的估计总额度。
- 额度历史更稳：5h / 7d 曲线兼容不同写入来源，明显异常的 100 / 0 跳点和回跳不会再把曲线拉出坑。
- 重置卡详情同步新信息架构：主界面显示可用卡数量和最近到期时间，详情列表默认收起，按最近到期排序，展开后只展示原因、关联用户、到期时间、剩余时间和卡片编号。
- README 更新为双平台说明：macOS 明确走 Swift 版，Windows 明确走 Tauri 版，并说明 x64 / ARM64 的安装包选择。

## 更新说明

- macOS 版使用 Sparkle appcast 更新；Windows 版当前先通过 GitHub Releases 手动更新。两个更新通道不会混用。
- Windows 安装器当前未使用商业代码签名证书，首次运行可能出现 Microsoft Defender SmartScreen 未知发布者提示。请只从官方 GitHub Release 下载并校验 SHA256。
- macOS 构建仍是 ad-hoc 签名，尚未 Apple notarize。如果 macOS 提示“未知开发者”，请从官方 Release 下载并校验 SHA256 后再打开。
- 速率显示只用于判断 Codex 是否正在工作，不代表精确真实吞吐。官方为避免高频日志写入损耗硬盘，已经砍掉了很多流式输出日志。
- 额度反推是估算工具，7d 下降太少、记录颗粒度太粗或遇到异常额度点时，结果可能偏差较大；界面会显示 7d / 5h 倍率辅助判断可信度。
- 本地 token、缓存命中、会话统计、额度历史和重置卡信息仍然来自本机 Codex 数据与本地账号接口。
- Codex Token Bar 不会上传 prompt、输出、日志、会话内容或账号额度。
- Windows ARM64 安装器进程可能经模拟运行，但安装后的 App 二进制是 ARM64。

## English

This release turns Codex Token Bar into a two-platform release: macOS continues to use the native Swift app, while Windows gets its first Tauri + React + Rust build. The same GitHub Release provides the macOS DMG plus separate Windows x64 and Windows ARM64 installers.

## Highlights

- Adds the Windows build with separate `windows-x64` and `windows-arm64` NSIS installers.
- Keeps the macOS build on the native Swift lane, with the DMG installer and Sparkle update checking.
- Makes usage refresh incremental: manual and automatic refreshes still perform real refreshes, but only new or changed session files are processed whenever possible.
- Makes live rate feel more like a work-intensity estimate: lightweight smoothing, display caps, and tool-input estimation reduce unrealistic spikes, while tool outputs and patch results do not inflate tok/s.
- Adds a live-rate off switch: the dashboard shows the disabled state, and the floating-panel rate module follows the same setting.
- Enables the Windows floating panel with live speed, total/today/current counts, 5h / 7d quota, reset-credit count, model IQ, and compact pace hints.
- Adds quota back-estimation: select a range on the recent 24-hour chart to estimate 5h / 7d total quota from token usage, cache hit rate, official API pricing, and quota drops.
- Stabilizes quota history by merging compatible sources and filtering impossible 100 / 0 quota jumps from charts.
- Aligns reset-credit details with the new information architecture: the dashboard keeps the available count and nearest expiry, rows stay collapsed by default, and expanded rows show only reason, linked user, expiry time, remaining time, and card ID.
- Updates the README for the two-platform split: macOS uses the Swift build, Windows uses the Tauri build, with clear x64 / ARM64 installer choices.

## Update Notes

- The macOS build updates through Sparkle appcast. The Windows build currently updates manually through GitHub Releases. The two update lanes are intentionally separate.
- Windows installers are currently not signed with a commercial code-signing certificate. Microsoft Defender SmartScreen may warn about an unknown publisher on first launch. Download only from the official GitHub Release and verify SHA256.
- The macOS build remains ad-hoc signed and is not Apple notarized. Verify the SHA256 checksum before opening if macOS warns about an unidentified developer.
- Live rate is only a rough signal that Codex is working, not an exact throughput measurement. Official Codex builds now suppress many high-frequency streaming logs to avoid excessive disk writes.
- Quota back-estimation is approximate. If the 7d quota barely moves, history granularity is coarse, or anomalous quota points appear, the result may drift; the UI shows the 7d / 5h ratio as a confidence hint.
- Local token usage, cache hit rates, session statistics, quota history, and reset-credit data still come from local Codex files and local account endpoints.
- Codex Token Bar does not upload prompts, outputs, logs, conversation content, or quota data.
- The Windows ARM64 installer process may run under emulation, while the installed app binary is ARM64.
