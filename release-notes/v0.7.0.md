# Codex Token Bar v0.7.0

这次更新把 Codex Token Bar 从 macOS 专属推进到双平台：macOS 继续使用 Swift 原生版，Windows 首次提供 Tauri + React + Rust 版本，并分别打包 x64 和 ARM64 安装器。

## 更新亮点

- 新增 Windows 版本：提供 `windows-x64` 和 `windows-arm64` 两个 NSIS 安装包。
- Windows 版接入本地 Codex 数据：读取 `sessions/`、`state_5.sqlite`、额度历史、实时速率和 Codex 雷达数据。
- 悬浮窗在 Windows 版可用：支持实时速率、总/今/次统计、5h / 7d 额度、重置卡数量、模型 IQ 和趣味节奏提示。
- 实时速率对齐 Swift 口径：主界面、悬浮窗和状态栏/托盘共享同一份速率快照；工具输出和 patch 结果不会制造虚高 tok/s。
- 用量统计改为增量缓存：启动和刷新时尽量只处理新增或变化的会话文件，降低大 Codex 历史库下的卡顿。
- 额度历史更稳：5h / 7d 曲线兼容不同写入来源，异常回跳不再把曲线拉出坑。
- 重置卡详情同步 Swift 信息架构：列表默认收起，按最近到期排序，展开后只展示原因、关联用户、到期时间、剩余时间和卡片编号。
- README 更新为双平台说明：macOS 明确走 Swift 版，Windows 明确走 Tauri 版，并说明 x64 / ARM64 的安装包选择。

## 更新说明

- Windows 安装器当前未使用商业代码签名证书，首次运行可能出现 Microsoft Defender SmartScreen 未知发布者提示。请只从官方 GitHub Release 下载并校验 SHA256。
- Windows 版当前先通过 GitHub Releases 手动更新；macOS Swift 版继续使用 Sparkle 自动检查更新。
- 这仍然是本地优先版本：App 只读取本机 Codex 文件、本地账号接口和公开 Codex 雷达订阅，不上传 prompt、输出、日志或额度历史。
- Windows ARM64 安装器进程可能经模拟运行，但安装后的 App 二进制是 ARM64。

## English

This release moves Codex Token Bar from macOS-only to a two-platform product: macOS continues to use the native Swift app, while Windows gets its first Tauri + React + Rust build with separate x64 and ARM64 installers.

## Highlights

- Adds the Windows build with separate `windows-x64` and `windows-arm64` NSIS installers.
- Connects the Windows build to local Codex data: `sessions/`, `state_5.sqlite`, quota history, live rate data, and Codex Radar.
- Enables the floating panel on Windows with live speed, total/today/current counts, 5h / 7d quota, reset-credit count, model IQ, and compact pace hints.
- Aligns live-rate behavior with the Swift build: dashboard, floating panel, and status/tray surfaces share one live snapshot, while tool outputs and patch results do not inflate tok/s.
- Adds incremental usage caching so startup and refresh paths process only new or changed session files whenever possible.
- Stabilizes quota history by merging compatible sources and filtering impossible 5h / 7d quota jumps from charts.
- Aligns reset-credit details with the Swift information architecture: collapsed rows, nearest-expiry sorting, and concise expanded fields.
- Updates the README for the two-platform split: macOS uses the Swift build, Windows uses the Tauri build, with clear x64 / ARM64 installer choices.

## Update Notes

- Windows installers are currently not signed with a commercial code-signing certificate. Microsoft Defender SmartScreen may warn about an unknown publisher on first launch. Download only from the official GitHub Release and verify SHA256.
- The Windows build currently updates manually through GitHub Releases. The macOS Swift build continues to use Sparkle update checking.
- Codex Token Bar remains local-first: it reads local Codex files, local account endpoints, and the public Codex Radar feed, and does not upload prompts, outputs, logs, or quota history.
- The Windows ARM64 installer process may run under emulation, while the installed app binary is ARM64.
