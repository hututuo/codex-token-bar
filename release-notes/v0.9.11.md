# Codex Token Bar v0.9.11

## 简体中文

修复部分用户覆盖安装 0.9.10 后仍停留在“账本准备未完成”的问题，Mac 与 Windows 同步更新。

- 修复每日维护时钟正常推进、额度观察继续追加后，未完成迁移被误判为旧账改写的问题；旧观察和账户归属仍完整核验。
- 完善 Exact 索引接续：区分运行元数据与历史消费，验证已知解析修复与原文关联；已发布的历史用量保留，原文不可用的关联仍保持不可用，不合并重复副本、不重复计账。
- 加强恢复目标保护：现有分区若出现冻结快照之外的记录，拒绝覆盖；真正替换前会在写入事务内再次核对。
- 保留原始会话、旧账、迁移备份和中断恢复证据；金额改写、归属冲突、已知指纹矛盾或无法证明的变化继续安全拒绝。
- 补充组合故障、启动、中断恢复和重复启动的双端回归。
- 修复侧栏三级菜单在汇总范围丢失24小时Codex额度曲线的问题；稀疏额度采样也能显示，不伪造缺失窗口。

遇到旧版启动提示的用户可直接覆盖更新，无需先卸载或删除数据目录。请保留旧数据库与迁移清单。

- Preserve original sessions, accounting history, migration backups, and recovery evidence. Changed historical amounts, ownership conflicts, conflicting known fingerprints, and unproved transitions remain safely rejected.
- Add cross-platform regression coverage for the combined incident, startup, interruption recovery, and repeated startup.
- Restore the sidebar detail's 24-hour Codex quota trend in aggregate scope. Sparse observations remain visible without inventing missing quota windows.

Install over the existing version without uninstalling or deleting data directories. Keep old databases and migration receipts.
