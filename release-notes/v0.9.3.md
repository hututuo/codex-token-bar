# Codex Token Bar v0.9.3

## 简体中文

- 额度改为直接请求官方接口，读取当前 Codex 登录对应的额度，不依赖模型服务商配置。
- 增加 Reserve 储备额度展示：接口返回可识别的储备窗口时，单独显示其剩余额度和重置时间。
- 低缓存命中提醒改为完整的二级侧栏面板，突出命中率、会话标题和排查提示；关闭按钮更明显，也可点击其他应用或在移入后移开鼠标收起。
- 修复 macOS 提醒图标被裁切的问题，并同步 Windows 侧栏的关闭与显示行为。

普通 API Key 不支持订阅额度查询；登录过期时，请先在 Codex 中重新登录。

## English

- Quotas now come directly from the official endpoint for the current Codex login, independent of model-provider settings.
- Adds a separate Reserve quota display, including remaining quota and reset times when the endpoint returns recognized Reserve windows.
- Low-cache-hit alerts now use the full second-level sidebar, with a clear hit rate, session title, and troubleshooting guidance. Alerts have a more visible close button and can also be dismissed by clicking another app or leaving after entering the panel.
- Fixes cropped alert icons on macOS and synchronizes sidebar display and dismissal behavior on Windows.

Ordinary API keys cannot query subscription quotas. If the login expires, sign in again in Codex.
