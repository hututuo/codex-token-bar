# Codex Token Bar v0.9.3

## 简体中文

- 额度改为直接请求官方接口，支持跟随当前登录或切换已保存的 ChatGPT 账号，并可添加、更新、导入和移除额度账号。
- 额度账号与本地用量统计分开管理；切换额度账号时清除上一账号的额度和历史展示，避免旧请求结果串号。
- 增加 Reserve 储备额度展示：接口返回可识别的储备窗口时，单独显示其剩余额度和重置时间。
- 低缓存命中提醒改为完整的二级侧栏面板，突出命中率、会话标题和排查提示；关闭按钮更明显，也可点击其他应用或在移入后移开鼠标收起。
- 修复 macOS 提醒图标被裁切的问题，并同步 Windows 侧栏的关闭与显示行为。

保存账号的访问凭据使用 macOS 钥匙串或 Windows 用户级加密存储。普通 API Key 不支持订阅额度查询；已保存账号的登录过期时，请在原客户端重新登录后更新账号凭据。

## English

- Quotas now come directly from the official endpoint. Follow the current login or select a saved ChatGPT account, with controls to add, update, import, and remove quota accounts.
- Quota accounts are managed separately from local usage totals. Switching accounts clears the previous quota and history view, and rejects stale responses from earlier selections.
- Adds a separate Reserve quota display, including remaining quota and reset times when the endpoint returns recognized Reserve windows.
- Low-cache-hit alerts now use the full second-level sidebar, with a clear hit rate, session title, and troubleshooting guidance. Alerts have a more visible close button and can also be dismissed by clicking another app or leaving after entering the panel.
- Fixes cropped alert icons on macOS and synchronizes sidebar display and dismissal behavior on Windows.

Saved access credentials use macOS Keychain or Windows user-scoped encryption. Ordinary API keys cannot query subscription quotas. If a saved account expires, sign in again in the original client and update its saved credentials.
