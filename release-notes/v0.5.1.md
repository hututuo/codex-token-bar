# Codex Token Bar v0.5.1

这次是一次比较大的体验和可靠性更新，重点打磨账号额度、悬浮/状态栏 token 显示、未读会话提醒、本地修复工具和最近用量曲线。

## 更新亮点

- 增强账号额度显示：加入 5h / 7d 额度历史、重置时间、本地轻量心跳记录和更紧凑的节奏提示。
- 新增重置卡详情：从 Codex 本地账户接口读取可用重置机会，展示卡片状态、到期时间、关联头像和来源说明。
- 加入未读会话提醒：Codex 任务完成后，如果对应会话还没点开，悬浮窗会显示柔和的涟漪或扫光提醒，点开后自动收起。
- 改进悬浮 token 小窗：支持更可靠的缩放、自定义背景渐变、透明度、速率满格值、提醒样式和窗口锁定跟随。
- 完善状态栏实时模式：菜单栏直接显示实时 tok/s，点击可展开白色详情卡，查看累计 Token、今日用量、额度和实时组成。
- 增加缓存命中分析：支持按每日、每小时、会话和单轮对话查看缓存命中率，并在最近用量图中显示命中率曲线。
- 优化 24h / 7d / 30d 曲线：修正平滑过冲、hover 点错位、额度线断裂，并利用重置时间补齐额度曲线。
- 重做“会话消失修复”流程：把扫描、备份、修复、验证做成更清晰的步骤，并加入备份回滚列表。
- 优化启动和滚动性能：减少重复数据库读取，缓存热力图和曲线准备结果，移除低价值的大面积视觉特效，并修复宽窗口两侧留白区域无法滚动的问题。
- 修复多项本地数据边界问题：包括 fork 会话 token 重放尖峰、subagent 未读误报、Codex Desktop 侧边栏可见性修复逻辑等。

## 更新说明

- Sparkle 会在开启自动更新后读取 GitHub appcast，也可以通过 `Codex Token Bar -> Check for Updates...` 手动检查。
- 更新仍然需要用户确认；App 不会在后台静默替换本地应用。
- 当前构建仍是 ad-hoc 签名，尚未 Apple notarize。如果 macOS 提示“未知开发者”，请从官方 Release 下载并校验 SHA256 后再打开。
- DMG 安装包流程加入背景图、拖拽布局和窗口尺寸验收，减少安装窗口缺背景或说明文字被截断的问题。
- Codex Token Bar 仍然保持本地优先：只读取本地 Codex 文件和账户额度接口，不上传 prompt、输出、日志或额度历史。

## English

This release is a large polish pass for quota visibility, floating and menu-bar token displays, unread session reminders, local repair tools, and chart reliability.

## Highlights

- Adds richer account quota visibility, including 5h / 7d quota history, reset timing, local heartbeat samples, and compact pace hints.
- Adds reset-credit details from Codex's local account API, with readable card status, expiry, user avatar, and source information.
- Adds unread session reminders: when a Codex task finishes and the session has not been opened yet, the floating panel can show a subtle ripple or shimmer cue and clear it after the session is opened.
- Improves the floating token meter with better scaling, custom background gradients, opacity controls, configurable full-scale rate, reminder styles, and a more reliable window-lock mode.
- Improves the menu-bar realtime mode: the menu bar can show live tok/s directly, and clicking it opens a white detail card with totals, today's usage, quota, and realtime breakdowns.
- Adds cache-hit analytics across daily, hourly, session, and turn-level views, including cache hit-rate display in the recent usage chart.
- Refines the 24h / 7d / 30d usage chart with better smoothing, aligned hover points, optional quota lines, and reset-time-aware quota continuity.
- Reworks the session disappearance repair flow with clearer scan / backup / repair / verify steps and a rollback list for previous backups.
- Improves startup and scroll performance by reducing repeated database work, caching expensive chart preparation, removing low-value heavy visual effects, and fixing scroll hit-testing in wide-window side gutters.
- Fixes several local-data edge cases, including forked-session token replay spikes, unread subagent filtering, and Codex Desktop sidebar visibility repair logic.

## Update Notes

- Sparkle checks the GitHub appcast when automatic update checks are enabled, or when you choose `Codex Token Bar -> Check for Updates...`.
- Updates are still user-confirmed; the app does not silently install a new version in the background.
- The app remains ad-hoc signed and is not Apple notarized. Verify the SHA256 checksum before opening if macOS warns about an unidentified developer.
- The DMG packaging flow now validates the installer background, drag-to-Applications layout, and Finder window size to avoid missing backgrounds or clipped guidance text.
- Codex Token Bar remains local-first: it reads local Codex files and account quota APIs, and does not upload prompts, outputs, logs, or quota history.
