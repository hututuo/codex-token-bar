# Codex Token Bar v0.9.1

v0.9.1 继续收敛双端图表、雷达和悬浮窗的交互与显示口径，重点修复“看起来像旧数据/错位数据”的体验问题，并让缓存排行与额度统计更贴近真实用户轮次。

## 更新亮点

- **图表默认查看最新数据**：24 小时、7 天和 30 天图表启动后定位到最新时间段；横向滚动条保持可见，时间标注、悬停竖线、气泡和区间选择在 Swift 与跨平台版保持一致。
- **图表比例和交互更稳定**：Token 纵轴按当前可见数据自适应，金额和缓存命中率使用独立映射；选区第二个点点击后立即汇总，悬停预览不再挡住曲线。
- **雷达与悬浮窗对齐**：速登窗口倒计时结束后会回到正常“速登窗口”状态；普通雷达和悬浮窗的等待/动作—IQ 分割线分别按各自布局收紧，双端保持一致。
- **缓存命中排行更接近真实轮次**：默认使用单轮最新口径，工具调用不再被误算成用户轮次；命中率分母使用压缩后的当前上下文窗口；排行支持完整查看、搜索和悬停查看被截断的问题/回答。
- **额度和状态栏细节修复**：状态栏实验开关默认关闭并明确标记；悬浮窗额度到期时间精确到分钟，重置卡和额度显示继续保留。
- **安全与稳定性**：Codex 运行中允许安全删除已完成归档会话；保留现有索引兼容、隐私和双端增量刷新边界。

## 更新说明

- 精确索引和历史聚合仍是本地可重建缓存，不保存会话正文，也不会上传本地用量。
- macOS 构建采用 ad-hoc 签名且未经过 Apple notarization；Windows 安装器未使用商业代码签名证书，首次安装可能出现系统安全提示。
- 正式发布后请只从官方 GitHub Release 下载，并使用随包提供的 SHA256SUMS-v0.9.1.txt 核对文件。

## English

# Codex Token Bar v0.9.1

v0.9.1 continues aligning chart, Radar, and floating-window behavior across both editions. It focuses on removing stale-looking or misaligned displays and making cache ranking and quota accounting follow real user turns more closely.

## Highlights

- **Open charts at the newest data**: the 24-hour, 7-day, and 30-day charts start at the latest time range; the horizontal scrollbar remains visible, while time labels, hover guides, bubbles, and range selection stay aligned across Swift and the cross-platform edition.
- **More stable chart scale and interaction**: the Token axis adapts to the currently visible data, with independent mappings for cost and cache hit rate; the second range point summarizes immediately and hover previews no longer cover the curve.
- **Aligned Radar and floating panel**: when the speed-window countdown ends, the UI returns to the normal speed-window state; the waiting/action–IQ divider is tightened per platform-specific layout while keeping Swift and Tauri consistent.
- **Cache ranking follows real turns**: the default is latest single-turn accounting, tool calls are no longer mistaken for user turns, and the hit-rate denominator uses the compressed current context window. Full ranking, search, and hover details are available for truncated questions and answers.
- **Quota and status-bar details**: the experimental status-bar toggle is off by default and labeled explicitly; floating quota expiry is shown to the minute while reset-credit and quota information remains available.
- **Safety and stability**: completed archived conversations can be safely deleted while Codex is running; existing index compatibility, privacy, and dual-platform incremental-refresh boundaries remain unchanged.

## Update Notes

- The exact index and historical aggregates remain local rebuildable cache data. Conversation text is not stored or uploaded.
- The macOS build is ad-hoc signed and not Apple-notarized. Windows installers do not use a commercial code-signing certificate, so the operating system may show a first-install warning.
- After publication, download only from the official GitHub Release and verify the bundled SHA256SUMS-v0.9.1.txt.
