# Codex Token Bar v0.9.7

## 简体中文

- 额度和重置卡改由本机 Codex 官方接口查询，复用一个后台子进程，减少反复初始化。额度与卡片共享查询结果，并处理超时、断线重连和退出清理。
- 恢复可关闭的低缓存命中提醒：按实际返回的输入与缓存 token 判断，提示可能由模型、思考强度或上下文变化造成的低命中。
- 续问时限建议、缓存间隔图及其额外扫描仍停用。缓存命中统计、费用账本和已有历史数据保留。
- 保留 v0.9.6 的 Windows 自定义启动入口保护与 RadarBench v6 兼容修复；适配新版 macOS Codex 的内置 CLI 目录。

额度查询需要本机已安装并登录 Codex。macOS 最低 14，当前 Mac 包为 Apple Silicon；Windows 提供 x64 和 ARM64。macOS 为 ad-hoc 签名、未公证，Windows 安装包没有商业代码签名；自动更新使用各自的更新签名验证。

## English

- Query quota and earned reset cards through the local official Codex interface. Reuse one background child process, share the returned snapshot, and handle timeouts, reconnects and owned-process cleanup.
- Restore optional low-cache-hit reminders based on reported input and cached tokens, with model, reasoning-effort and context changes explained as possible causes.
- Follow-up timing recommendations, cache interval charts and their extra scanner remain disabled. Cache accounting, the cost ledger and existing history are retained.
- Keep the Windows custom-launcher protection and RadarBench v6 fixes from v0.9.6, and recognize the current macOS bundled Codex CLI location.

Quota queries require a locally installed and signed-in Codex. macOS 14 or newer is required; the Mac package is for Apple Silicon. Windows x64 and ARM64 packages are included. The Mac app is ad-hoc signed and not notarized; Windows installers do not have a commercial code-signing certificate. Both automatic-update lanes verify their respective update signatures.
