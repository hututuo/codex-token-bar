# Codex Token Bar v0.9.9

## 简体中文

本次为升级兼容性修复，重点解决部分 Windows 用户更新后无法进入应用的问题。

- 修复把旧版本正常保留的迁移清单误判为未完成迁移，导致出现“账本准备未完成”的启动拦截。
- 自动核验并接续可信旧账本，兼容升级中断、已有部分新库，以及之后再接入旧数据目录的情况。
- 保留原始数据库、回滚库和迁移材料；候选库不作为已提交账目导入。真正缺库、损坏或未知格式仍会保护性停止并提示。
- 修复账本内部复制的外键顺序问题及 Windows 首次创建目录时的索引路径识别问题。

如果 0.9.8 已无法进入应用，请下载对应的 Windows 安装包直接覆盖安装 0.9.9。无需先卸载，也不要删除数据目录、迁移清单或旧数据库。

Mac 与 Windows 同步更新。macOS 包为 Apple Silicon、ad-hoc 签名且未公证；Windows 提供 x64 和 ARM64 安装包，无商业代码签名。自动更新继续使用原有 Sparkle 与 Tauri 更新签名。

## English

This compatibility patch fixes a startup failure affecting some Windows users after upgrading.

- Fix a false “Ledger preparation incomplete” startup block caused by migration receipts intentionally retained by earlier versions.
- Validate and resume trusted legacy ledgers, including interrupted upgrades, partially initialized new containers, and legacy data directories added later.
- Preserve original databases, rollback databases, and migration evidence. Never import uncommitted candidate data as recorded usage. Missing, corrupt, or unknown-format sources still stop safely with a diagnostic.
- Fix foreign-key ordering during internal ledger copies and Windows index-path identity when directories are first created.

If version 0.9.8 cannot open, download the matching Windows installer and install 0.9.9 over the existing installation. Do not uninstall first or delete the data directory, migration receipts, or old databases.

Both Mac and Windows are updated. The Apple Silicon Mac package is ad-hoc signed and not notarized. Windows x64 and ARM64 installers have no commercial code-signing certificate. Automatic updates retain the existing Sparkle and Tauri update signatures.
