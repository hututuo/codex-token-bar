# 主页汇总：取消按客户端重复整块图表

用户再次明确：汇总是数值聚合，不是在页面下方按客户端复制模块。本轮先修改跨平台实际组件并提供本机真实历史数据的只读预览；未打包、未安装、未重启正式版，原生同步仍待后续完成。

## 已实现的跨平台行为

- DashboardAnalyticsSection 不再遍历客户端生成多套视图。当前范围只对应一套热力图、一张用量曲线、一个缓存排行。安装/发现但没有数据的客户端不产生占位大块。
- Token、输入、输出、调用按时间桶相加；缓存命中率按输入量加权。缓存字段不完整时标未知，不补成0命中。日历沿用本地日期；Codex 原有日期、模型明细和额度观测保留。
- 额度百分比属于账户和窗口，不相加。汇总图保留 Codex 额度曲线；Codex 金额/选区反推单独对齐原始 Codex 时间桶，其他客户端消耗不套 Codex 单价。图例注明金额来源。其他客户端现有时间桶缺少逐模型金额，本轮没有伪造补算。顶部各客户端的已知模型费用汇总仍沿用原功能。
- 缓存排行复用原有列表、排序和详情，混合列出带客户端标识的 Codex 轮次和其他客户端的会话。后者没有可靠轮次边界，不冒充轮次。客户端/会话键有命名空间，避免 UUID 相同被合并。仅对有真实请求的所选客户端，通过既有只读本地命令获取缓存排行；没有新增网络请求。
- 本地请求明细保留客户端/会话标识，按当前已加载批次显示，可继续加载至既有限额5000；此接口仍是客户端级分页，尚未新增会话级查询。范围切换时关闭旧会话详情。

## 数据与性能边界

未修改数据库、原始JSONL、扫描器、两库结构、价格表、TPS或内存速度图。聚合投影按来源和范围 memoize；取消重复热力图和用量图的 DOM、动画及图表计算。查询随多客户端快照更新，不绑定速度刷新。

现有其他客户端桶无法证明每桶所有请求的缓存字段完整时，先沿用客户端完整性保守约束；后续可增加逐桶缺失计数，避免一条旧缺字段记录影响其他完整桶。本轮不以放松未知数据判定换取显示数值。
