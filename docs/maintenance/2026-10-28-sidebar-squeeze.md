# 一级／二级侧栏：向内压合与模型占比对应

## 原因和调整

旧整环动画把左右两半分别投向直条的上下两段。其中一半的纵向点序在过程中反转，产生拧转观感。现保持两侧都从下到上的点序，横向压拢成细椭圆，最终重合为一根完整直条；不再反向翻折。两侧共用透明度合成组，合拢处不会叠亮，终点保持实际额度比例。

原生窗口、非线性时间曲线、440ms 总时长及文字淡入淡出沿用已有实现。没有改窗口尺寸调度、速度计算或业务数据。

| 内容 | 展开与收起对应 |
| --- | --- |
| 单周期额度 | 整圈 ↔ 一根完整额度条 |
| 双周期额度 | 左右各半圈 ↔ 各自的一根完整额度条 |
| 速度 | 模型颜色组成的环 ↔ 同色段速度条 |
| 任务 | 原任务轮廓 ↔ 原任务状态条，不引入进度百分比 |
| 模型占比 | 原横向色带 ↔ 原竖向色带，颜色顺序、占比保持 |

模型占比过去只分别绘制横条和竖条，未注册匹配动画。现补源／目标锚点、参与者及 strip 路径适配，继续复用 `MatchedStrokeMorph`，不另建菜单。

无信息的一级绿色占位点已在前一个提交 bbea6db6 删除。仅速度、额度、模型占比和任务具有一级图形；模型检测、正文 TPS、雷达等仍保留二级入口。额度品牌标记与真正告警保留。

## 双端边界

- macOS：保留现有 CA 瞬时层内核，仅调整几何对应及补充模型占比路由。
- Tauri：此前只匹配移动额度品牌点、环条本体交叉淡入淡出。现增加 SVG 路径对应，接入同一开合事件；客户端点沿用旧路径。速度、任务、模型占比使用原组件，抽出 `SidebarActivityStrokes.tsx` 供主侧栏与验证页面共用。
- 两端的点序、整环压合规则和终点比例需同步维护：`ClientQuotaMorph.swift` 与 `sidebarStrokeGeometry.ts`，对应 Swift／Node 几何测试。
- 浏览器一次提交有界动画，不使用逐帧 JS、轮询或额外采集。快速反向读取当前呈现路径；完成／卸载恢复原组件并移除临时层。减少动态效果时不启用；不支持或执行失败时保留原淡入淡出。
