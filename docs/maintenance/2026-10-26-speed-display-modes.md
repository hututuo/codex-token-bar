# 本地速度切换与多客户端彩条（2026-10-26）

本文为源码和组件验证记录。用户随后授权替换，Mac已安装[build960](2026-10-26-speed-display-build960.md)；Windows安装版未替换。未发布，未合入 `codex/multi-client-tokens`。

## 产品行为

- 保留活动估算（原 Codex 曲线，默认）和榜单口径（Agent Speed 算法）两个选择。榜单口径支持本地 Codex、Claude Code、DeepSeek Harness/DSH 等上游已支持的数据源。
- 彩条单独选择按模型或按客户端分段，分段宽度为各项对当前本地显示 TPS 的贡献。模型色与其他图表使用同一配色入口；客户端键为 `client:codex` / `client:claudeCode` / `client:deepseek` 等。
- 主界面“彩条颜色”支持修改和恢复默认，持久保存。原有用户默认保留活动估算、按模型和既有模型颜色。
- 榜单模式的本地显示逐会话过滤：确认结束/中断/错误则清零；无新日志达到20秒则清零；读取器快照超过3秒则清零。一个会话停止不影响其他会话，恢复后的新事件可以重新显示。无法从日志判断尚未落盘的网络错误时，依靠停更超时；不宣称能直接检测所有网络断开。
- 上报只使用原始 Agent Speed 快照；上述显示过滤和自定义颜色不进入报文、Token统计、金额或签名。是否上报仍是独立默认关闭的用户选项。
- 两种算法的近30分钟本地速率曲线分开保存为有界内存历史；不会拼接不同算法。模型分组用于金额换算，切换为客户端配色也不会把客户端名字当价格模型，缺价格继续显示未知。
- Claude Code/DSH 的正文 TPS 尚未伪造接入。本机 Claude 历史缺正文自身起止时间，继续与榜单请求速度区别展示。

## 实现边界

macOS：`SharedAgentSpeedCollection` 使用租约共享一个本地读取器，显示和报告独立持有租约。仅启用本地显示不连接发现服务、不注册设备、不创建签名密钥。显示关闭且上报未启用时停读取器。休眠清空本地显示，唤醒重建读取器；租约释放时自动停止无消费者的读取器。

Windows：一个常驻 helper 共用一个 LiveMonitor。`{"enabled":false,"localDisplay":true}` 是不进入身份、注册和网络路径的本地模式。注册/签名等报告错误不会杀死仍有本地显示需求的读取器。Rust每500ms快照读取只访问内存缓存，不读取设置文件；EOF/子进程退出清除显示值。设置保存持久化后广播给窗口。浮窗、状态面板只获读取权限，设置修改仍限定主窗口和侧栏。

上游改动仅添加显示停止标记并投影到 AgentStatus，不改原始计时、阶段、账本或报告数学。见 `Vendor/AgentSpeed/VENDOR.md`。
