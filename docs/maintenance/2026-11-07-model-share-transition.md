# 一级、二级菜单模型占比切换修复

基线 `9105e989`，分支 `codex/legacy-debt-20261104`。

## 原因与修复

一级竖条、二级横条和切换动画已经使用同一份今日模型 Token 占比、顺序与配色。本次复现的跳动来自绘制几何：静态组件按完整条长分配颜色，动画却先从两端各扣 2px，再为每段颜色添加圆头。相邻颜色因此互相覆盖，动画交还给静态组件时边界会移动。

Swift 和 Tauri 动画现在都按完整条长分配颜色，内部边界使用平头，仅用独立圆角轮廓裁剪整条。反向切换会接续正在显示的颜色路径和裁剪轮廓。空数据轨道与静态背景保持一致；Swift 仅保留模型模块时也启用相同切换动画。

浏览器实测还发现 CSS flex 子块会把 14.5px 的边界绘制到 15px。Tauri 横条与竖条因此统一复用 `SidebarModelShareStrip`，用完整 SVG 路径表达占比，保留数据变化时的过渡、自定义模型颜色和减少动态效果设置。

没有改动模型份额计算、额度读取、金额计价、数据库和采集器。额度环和十格任务条仍走原来的几何分支。
