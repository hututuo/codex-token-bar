- Swift / Rust 从既有 `speed_5m` 读取已完成的五分钟桶，按模型分组。24h / 7d / 30d 图分别使用 30分钟 / 2小时 / 6小时区块。至少3个非空底桶、6段正文才画分布。

- 主页面和三级菜单移除旧均速折线、散点和“首尾变化”，改为独立分布色带与中位线。空时段不连线、不补零；悬停/点击空档不拿邻近数值顶替。保留统一模型颜色、紧贴分布范围的Y轴和弱网格。

- 分位数在现有后台读取路径计算，没有数据库迁移、改写旧桶、会话重扫、新额度请求或悬停查库。渲染端仍保留隐藏暂停轮询和等值快照隔离。
- 邀请页开关加高亮及两步提示；公开昵称/重复上报说明始终占固定位置。开关仍默认关闭，明确选择后按钮才可用。浏览器真实开关 off/on/off 高度均为689.7734375px（宽500px）；正式Mac邀请页也核对了按钮启用关系。
- 新录屏1684×1100、16秒、60fps播放、10,550,916字节。实际捕获610帧/19.92秒≈30.6fps，使用前16秒中的496帧，较旧约9.8fps提高三倍。按真实时间复帧为60fps，不合成排名、速度或虚构插帧。双端资源SHA256相同，见素材PROVENANCE。
