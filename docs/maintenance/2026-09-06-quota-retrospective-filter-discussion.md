# 额度历史先画后剔除：7d 主判、5h 最小干预

状态：已按用户批准方案实现于 Swift 和 Rust/Tauri，2026-09-07。本轮仅源码、测试和本地构建；未替换运行应用、未修改真实历史库、未发布。以下规则取代此前三次观测跨五分钟才显示的策略。

## 7d：候选立即显示，拒绝条件独立触发

剩余额度比前点升高且达到 98%–100%（used 降至 0%–2%）时创建事件。固定保存跳变前的 used/reset 和候选起点，观察期限严格为起点后 300 秒；低值延续不重开窗口。普通非零下降保留。

拒绝条件采用 OR，任一命中即回溯处理：

1. 300 秒内 used 实际上升并回到跳变前值 ±3 个百分点。候选已在该范围内时，不能把始终在范围内算作回跳，必须观察到离开再返回。
2. 候选后相邻成功观测的 `used增量 × 60 / 实际间隔秒数`：Plus 严格超过 10pp/min，Pro 严格超过 2pp/min。未知计划不套用，不限制间隔为 30–120 秒，不用于普通消耗或 5h。阈值是用户选择的跳变兜底条件，不是官方硬性消耗上限。
3. reset 离开旧值后在 300 秒内返回旧值（±5 秒）；或观察期满，持续有效新观测均保持旧 reset。后者要求相邻间隔及期末观测年龄均不超过 120 秒；缺失/中断不能证明 reset 一直没变。

期限包含第 300 秒；超过期限才取得的恢复点不用于该事件的回跳或速度判断。已有期内证据可以在期限结算，使用期内最后一份有效观测作为端点；不使用迟到的恢复观测补证。新 reset 稳定、向未来推进超过 900 秒或低 used 持续增长都不能豁免已命中的拒绝条件。

7d 新周期元数据阈值为 reset 向未来严格推进超过 900 秒；该阈值不是显示许可门槛。合法 used 在 0–100 内均可作为新周期首点。旧周期是否到期不参与拒绝，兼容提前重置和用卡。

## 5h：只处理同份响应中的单点尖峰

必须同时满足：跳变前 used>0；候选 used=0；下一有效观测在 120 秒内回到原 used±1 且 used>0；前中后三个 reset 一致（±5 秒）；同一原始观测的 7d 已被剔除。

其他情况全部保留，包括 5h 原本已满、多个低值点、reset 只改变几分钟、非零下降。5h 周期元数据仍使用原 1800 秒阈值，但阈值不能拒绝合法观测或阻断显式修复连线。

## 回放、连线与存储

- 每次拒绝保留当前触发点，剔除候选起点至当前点之前的对应窗口数据。触发点立即作为后续基线，不额外等待可靠恢复点。
- 显式连接跳变前点与保留端点，允许平线、剩余额度上升及跨周期连接；候选之前超过既有 90 分钟携带范围的长缺口不额外强制填平。连线是显示插值，不是新观测。
- 5h、7d 独立剔除，不能删除整行；原始身份和精确观测时间用于配对，不能按五分钟桶猜测。
- 身份隔离/跨库去重 → 完整保留时间线回放 → 按窗口过滤 → 周期重算 → 桶聚合/消费统计 → 可见范围。剔除点不进入日均值或消费观测。
- 原始写入仍保留每次成功的新观测及原 used/reset。重复、迟到响应不推进历史。没有新增数据库表、字段或公开 API 字段，也没有删除真实原始记录。
- 内部投影保留拒绝原因、索引和显式连线端点。读端从最早保留的本端周期偏移重算，避免被剔除的假 reset 留下最新周期偏移；原始写入兼容既有元数据。
- 实时额度显示保留接口原值。旧 reset 到期或回退不再单独隐藏合法新观测；观测之间的普通缺失仍按既有携带规则处理。
- Tauri 同一次历史 bundle 的日/近期/小时范围共用同一个判断时刻；查询范围裁剪前回放，重启后可重建相同结果。
