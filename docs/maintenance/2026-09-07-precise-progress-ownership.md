# 跨平台精确统计进度收尾修复

## 问题与行为

运行日志显示，精确统计在 10:33:23 成功，30 秒后的存储维护打开索引，24 毫秒后以 NotDue 返回。打开索引共用的进度回调把已完成状态改成“准备扫描”，维护没有对应的统计终态。页面结束主动刷新后也会停止轮询，使旧提示滞留。

存储维护现在以线程局部作用域抑制统计进度写入，退出作用域自动恢复；不保存再覆盖旧状态，避免干扰其他线程的新统计结果。前端在观察到非终态进度时继续轮询，收到 idle、complete 或 failed 后停止。正常统计任务、摘要终态、计算策略和原始数据均保持原有行为。
