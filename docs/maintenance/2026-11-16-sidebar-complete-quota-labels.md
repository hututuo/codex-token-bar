# 二级侧栏额度文字完整显示

build 1017 的原版二级菜单把每个周期标题限制在 34pt 单行区域。Antigravity 的 `Gemini · 5h`、`第三方模型 · 7d` 在该宽度下会缩小并出现省略号。

本次沿用原有 88pt 二级菜单和 46pt 额度圆环：同一额度池的名称独占完整标签行，下面左右显示「5小时 / 7天」。软件名、未知窗口和其他长标签采用自然换行，不再限制单行或缩小标签字体。没有改变一级紧凑额度组、额度来源、刷新节奏或数据库。

复用现有原生组件渲染检查，加入 Antigravity 两个额度池及小数值，云端输出 `sidebar-quota-complete-labels.png` 供核对真实宽度。按本仓库规定，编译、测试和打包均在云端执行。本地只进行语法解析、差异检查、候选完整性验证和已授权的应用替换。

build 1018 的云端组件图确认名称完整显示，但也暴露了小数值的既有截断：数字先被包进 20pt frame，再设置缩放，导致 `99.92` 仍显示省略号。修正为在 Text 本身应用单行缩放，再分配列宽，保留完整小数。

最终候选构建号为 1019；1018 未替换到本机。云端结果及安装证据在完成后补记。
