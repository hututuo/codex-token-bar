# 主页面历史单日模型金额

基线：`fba0116950f1699a5b4b6a738c332c060d172fb1`，分支 `codex/legacy-debt-20261104`。

## 用户可见行为

主页面模型费用上方增加“单日金额”。Codex 单独视图和多客户端汇总均可展开日历，点击某一天查看当日各模型金额和合计；支持月份前后切换、直接跳转日期和返回今天。未来日期不可选。“返回汇总”恢复原有今日、累计或周期范围；Codex 的历史订阅周期日历保留。

单日范围跟随当前所选客户端。日期在切换客户端时保留，金额重新读取；更换 Codex Home 或日期后，旧请求的迟到结果不得显示。相同日期、来源和客户端的常规刷新保留上次已提交结果，并显示刷新状态。

金额是本地已记录用量的参考 API 费用，不是提供方账单实扣。日历可查询保留账本中的历史日期，不限于当前趋势图的最近 7/30 天；缺失或从未采集的原始历史不能由日历恢复。

## 实现与兼容边界

- SwiftUI 和 React 使用本地日历的当天零点至次日零点，查询为左闭右开 `[start, end)`，兼容夏令时 23/25 小时日期。恰在次日零点的事件只属于次日。
- Codex 从当前已提交的 canonical 用量账本读取，不依赖订阅额度身份，也不为打开日历重新扫描日志或请求额度。沿用现有版本、发布状态、来源安全检查和带日期的模型计价。
- 其他客户端从现有 `client_usage_events` 只读查询，Token 汇总和逐事件计价使用相同的起止条件。复用历史价格、缓存字段、Antigravity 明确 effort 后缀与未知价格规则。读取不建库、不迁移、不修改事件、断点或版本。
- 某一来源不可用时仍显示其余来源的已知小计，并注明问题；压缩用量缺失仅标注受影响日期。全部来源不可用不显示 `$0.00`；已读来源没有记录与部分来源未读到分别提示。
- Tauri 新命令 `read_model_day_usage` 仅允许主窗口；Codex 读取绑定当前来源 token，限制单次查询最大 27 小时并校验客户端。没有新增外部 API、订阅轮询或偏好设置。

## 日历布局收束

单日选择直接复用两端已有的 `QuotaCycleCalendar`，通过单日选择参数扩展；原有周期色带和周期点击保持原有行为。独立日历的月份网格、布局代码和样式已删除，`ModelCostDayCalendar` / `ModelDayCalendar` 仅负责将单日选择接到共用组件。

日历随费用区域填满可用宽度，不再限制 350px；沿用原日历的 26px 日期行与紧凑间距，“跳转日期”和“今天”合并到月份标题行，去掉额外底部区域。仅调整组件和布局，查询与金额计算不变。合成预览中同一个五周月份宽 978px、高 214.3px，无水平溢出；上一版加宽日历约 320px 高。
