# 侧栏十格任务亮条

2026-11-05，基于 `9e63a5e76693cd269923b04c68e7316de265fd89`。

收起侧栏的任务条由固定半透明黄色改为十等分灯柱。每格代表一个当前运行的主任务或子 Agent，按模型分组、稳定排序，从下向上填充；颜色复用现有模型配色及用户颜色设置，不根据 harness 改写模型身份。原尺寸仍为 4 × 46，格间分隔为 0.6 点。展开圆环同样分十格，准确总数仍在圆心，主/子计数保留。

零任务显示十格暗底；模型字段未同步的已知任务显示灰格；只有过期快照时保留旧数量并变灰；来源不可用或读取中不会伪装成当前零任务。超过十个只亮十格，悬停说明显示完整总数和超出提示。条格是数量刻度，不是任务完成比例。

Mac 与 Tauri 均复用已有运行任务观测。多个客户端的当前观测仍按原规则汇总；只要有当前数据，其他来源的过期任务不进入当前计数或颜色。设置页预览使用同一组件；Tauri 的额外预览订阅仅在该预览挂载时存在。

展开/收起动画把每一格分别映射到圆弧和竖条，使用平直端帽保留细分隔线；速度、额度和模型占比的原动画保持原有端帽。每次变形新增的是固定数量的临时图层，完成后继续移除，无新增空闲动画定时器。
