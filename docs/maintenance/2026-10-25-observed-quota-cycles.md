## 定稿语义

- 同一稳定 Home / 账户 / 套餐 / 额度限制内，相邻有效已用读数下降至少 5 个百分点，立即以**这次观测时间**切分。本期费用采用该产品定义的观测起点，不声称它是服务器实际执行重置的时刻。
- 原始时间线可重算。任何时候，相邻读数上升至少 5 个百分点并回到某次下降前读数 ±3 个百分点，且本地账本证明 `(上一观测, 本次观测]` 没有 token 消耗，撤销最近匹配切分。没有确认等待或回弹时间上限。
- 本地账本为 Home 范围，没有逐事件账户归属。任意正消耗保守地阻止撤销；缺库、版本/世代/覆盖收据不匹配、读取失败、覆盖未到结束点都为 unknown，不能当成零。某些外部使用/迟到日志仍只能保守处理。
- 逐步消费回到旧百分比不撤销。未知或有消耗时保留已经切出的周期。
- resetsAt 只显示最新“下次重置”，不参与实际周期切分、确认或时钟过期判定。重置卡可不改变 resetsAt。
- 第一次观测以前的起点仍未知，不回填七天，不凭空补离线期间漏掉的周期。

## 数据与性能

- 额度原始读数、原始重置时间、费用事件账本均保留；不做删除式重建，不改精确用量数据库版本。
- 实际周期投影版本升为 3，启动首次读取保留历史回算；后续沿现有额度刷新推进。没有新增额度请求、会话扫描或常驻定时器。
- 按用量基线的 0…100 桶记录可撤销切分。只有明显上升时检查附近七个基线桶，避免整段历史向前查找；同次投影重复证据区间复用。
- 新周期费用对 canonical ledger 使用 `[起点, 终点)` 精确时间范围，按模型和日期分组，保留每个 token 字段及对应价格；不再把边缘整分钟列为待归属。相邻周期半开区间互补。
- 本期截止仍为最近额度观测与精确统计覆盖的较早者。当前周期不会仅因计划重置时间已到而自行结束。
- 7d 图表的派生周期标记同步按用量下降计算；5h 现有独立显示策略未纳入本次本期费用周期改动。
- 顶部额度与本期投影身份/版本/观察范围或本次下降起点不一致时，本地重算一次；持续不一致保留 stale，避免无限重试。Windows 明细读取遇到边界已改也在当次刷新内重读一次周期表。
