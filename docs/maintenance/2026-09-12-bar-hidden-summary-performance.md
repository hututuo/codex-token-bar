# 侧栏隐藏内容与倒计时性能复核

本轮基于 `f5d8f706`，继续在 `codex/bar-idle-performance-20260912` 上减少跨平台侧栏的重复工作。

## 修改

- 二级菜单收起时保留原有 220ms 透明度过渡；淡出结束后卸载内部数字、圆环、推荐和重置卡组件。定位外壳始终保留，一级色条继续更新。WebKit 未发送过渡结束事件时，320ms 的一次性兜底也会完成卸载。
- 隐藏期间不再构建或协调这棵内部组件树；重新展开时在同一次渲染中挂载最新数据，不补播隐藏期间的数字变化。快速重新展开会取消待执行的卸载。
- 雷达来源数据与时间相关字段分开计算。倒计时刷新只更新倒计时、有效窗口和新鲜度，复用已有排名数组；模型排序仅在来源快照变化时进行。额度、速率、雷达来源的刷新频率没有变化。

本轮没有改动吸附几何、动画帧率、速登红边、Swift 实现或索引与账本。不会触发数据库迁移或重扫。

浏览器页面复用生产 `SidebarRailContent` 与样式，外部裁剪窗口由测试页模拟，不能据此声称原生窗口动画或安装包已验收。测试页首次遗漏应用样式作用域，造成等待按钮伪元素覆盖其他按钮；补齐作用域后命中正常，未据此修改生产 CSS。热更新曾出现测试入口重复 createRoot 的警告，完整重载后另行核对。

构建仍有既有的分包大小与无效动态导入提示。本地过程记录与临时测试页存于 `runs/20260912-bar-animation/`，未纳入发布文件。

工作树原有 14 个文件的 UI / 升级兼容改动继续保留。本轮只提交上述性能修改；共用的 `QuotaSidebarApp.tsx` 按改动选择暂存，并导出暂存版本独立构建、测试。

这证明减少了隐藏组件更新和重复排序，尚不能换算为整体 CPU 从 2% 降到多少；当前运行的应用未替换。
