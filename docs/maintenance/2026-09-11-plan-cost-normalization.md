# 2026-09-11 套餐金额均一化

## 规则

按用户指定系数，在既有计费结果上逐模型换算：Sol ×1.0、Astra ×1.5、Luna ×2.0，其他已定价模型暂按 ×1.0。混合金额先分别换算再求和，不能给合计套单一模型系数。

原金额继续使用现有价格框架，包括事件时间价格、缓存输入、原有 Radar 价格版本、Auto Review 按时间路由、未知模型排除和 Spark 独立参考价。均一化金额是自定义估算，不是服务商公布的实际账单。没有引入 Fast 倍率或改动公开价格表。

订阅月费保持原额；累计净值的第二项为“均一化用量金额 − 同一笔订阅费用”，仅供对照，不代表现金收益。Spark 的独立参考价按未指定模型 ×1.0 展示，两项均不计入主额度合计。

## 展示范围

- Swift 与 Tauri：今日/本期/历史周期/累计模型明细及合计、周期边缘明细、悬浮窗费用页、热图费用、累计净值。
- 折线图：可见窗口金额、单点金额、框选金额、反推额度、本机归因可比金额与当前 API 金额。
- Radar 模型 IQ 成本：有可识别模型时换算；Radar 总额、趋势和套餐金额缺少模型明细时保留原额并标记“均一化待模型数据”。不猜测模型系数。
- 额度侧栏当前不展示美元数值，只有额度百分比、Token、速率、Agent 数及 Radar IQ，无需新增无关金额。
- 原始 API 单价、套餐月费、公式分母和图表金额坐标维持原口径；金额详情旁给出均一化估算，现有共享归因公式不改。

紧凑模型卡片上下两行显示，附系数说明。两端图表共用一次价格计算生成原额与均一化数组，复用现有缓存；没有新增轮询或扫描任务。

## 升级兼容

本功能仅增加内存中的金额派生值与 UI。没有修改索引 schema、原始 JSONL、事件账本、聚合缓存格式、原金额字段语义或正式版升级入口。已有 schema6/schema9 → schema13 升级策略不变，不要求重建或全库重扫。
