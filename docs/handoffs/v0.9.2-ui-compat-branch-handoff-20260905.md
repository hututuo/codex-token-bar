## 当前已经确认的 UI 默认行为

Swift 和 Tauri 的悬浮窗默认翻页配对统一为：

1. `todayModelShare` ↔ `todayModelCost`
2. `crowdRadar` ↔ `radar`

只有在用户没有保存 `pagePairs` 时才使用这些默认值。已有用户明确保存的拆分、顺序或其他配对必须原样保留，不能因为默认值改变而覆盖。

对应实现：

- `Sources/CodexTokenBar/FloatingPanelContentVisibility.swift`
- `tauri-app/src/floating/floatingContent.ts`
- `tauri-app/src-tauri/src/models/settings.rs`

## 后续 UI 修改边界

- Swift 端和 Tauri 端需要同时评估；不能只改一端就宣称跨端完成。
- 视觉验收由用户完成；代码侧负责尺寸计算、命中区域、关闭/重开、保存配置和窄屏边界。
- 不要把独立的雷达详情折叠状态误当成翻页配对配置；二者是不同设置。
- 修改配置读取时，优先确认使用的是正式 app bundle 的配置域，而不是裸 debug 可执行文件的独立 `UserDefaults` 域。
- 不改变统计索引、generation、staging、checkpoint 或数据库文件路径来解决单纯 UI 问题。

## 后续兼容修改边界

- schema 11 是当前双端精确索引基线；v0.9.1 只要求安全读取/拒绝，不做旧字段双写。
- 迁移、未知 schema、quick check、锁、磁盘或 I/O 异常只能返回 `lastGood` / `repairRequired`；不得 DROP、整表 DELETE、删除活动库或自动全量重扫 JSONL。
- 保留现有增量扫描、source ID、generation、staging、chunk、checkpoint 和单写者模型。
- 任何缓存/快照版本调整必须同时检查 Swift 与 Tauri 的旧版本读取、升级后只写新版本和失败回滚。
- 不修改 Provider Sync、会话删除、项目移动等写操作安全边界，除非用户另行授权。
