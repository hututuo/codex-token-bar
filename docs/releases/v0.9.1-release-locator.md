## 双平台发布边界

README 承诺同时提供 macOS、Windows x64 和 Windows ARM64。当前工作站只生成了 macOS 资产；`dist/release/v0.9.1/` 尚无 Windows 安装器、`.sig`、`latest-windows.json` 或 Windows checksum。因此不能在未补齐 Windows 资产或未明确采用 macOS-only 发布方案前创建统一的 `v0.9.1` GitHub Release。
