# Codex Token Bar v0.9.8

## 简体中文

本次更新加入多客户端本地用量统计，并重点修复升级兼容、历史账本保留和图表计价。

- 支持在 Codex、Claude CLI、Claude Desktop 与汇总范围之间切换；其他已支持客户端可按需启用。Claude 仅读取本地记录和已有额度缓存，不向 Anthropic 发起请求。
- 保留 Codex 历史账本，新增客户端及测速数据独立存储。升级前保留备份；归档、删除或移动原始会话文件不会删除已经记录的历史用量。
- 修复选区包含最后一个空时间格时金额突然跳涨的问题，使气泡、固定选区与明细使用同一份模型和用量快照。
- 新增正文 TPS 明细与速度分布；活动速率曲线保留原始采样点。改进模型配色、侧栏设置、多屏拖动吸附和展开收起效果。
- 提供可随时关闭、默认关闭的速蹬排行榜上报；只上报允许的统计字段，不上传对话内容或账号凭据。Claude 来源不参与上报。改善临时失败后的自动重试及 WebSocket 消息兼容。
- 同步修复 Codex 分页子 Agent 继承记录重复计算、Claude Desktop 工具结束后继续估速，以及 Mac 跨夜恢复会话后未及时读取的问题。
- 减少首页重复费用计算和数据库连接开销，增强旧版本升级、中断恢复、锁冲突和未知数据库版本的保护。

额度查询需要本机已安装并登录 Codex；Claude 额度仅在本地有有效缓存时显示。macOS 14 起，Mac 包支持 Apple Silicon；Windows 提供 x64 和 ARM64。Mac 应用为 ad-hoc 签名、未公证；Windows 安装包无商业代码签名。自动更新分别验证 Sparkle 与 Tauri 更新签名。

## English

This update adds local multi-client usage statistics and focuses on upgrade compatibility, historical ledger retention, and chart pricing.

- Switch between Codex, Claude CLI, Claude Desktop, and an aggregate view. Other supported clients can be enabled as needed. Claude reads only local records and existing quota caches; it makes no requests to Anthropic.
- Retain the Codex ledger while storing additional clients and speed measurements separately. Preserve upgrade backups and recorded usage when original sessions are archived, deleted, or moved.
- Fix the sudden cost increase when a selection includes the final empty chart bucket. Tooltips, pinned selections, and details use the same model and usage snapshot.
- Add body-TPS details and speed distributions while retaining raw activity-rate samples. Improve model colors, sidebar settings, multi-monitor dragging and docking, and expansion transitions.
- Offer optional leaderboard reporting, disabled by default and switchable at any time. Only permitted statistics are uploaded, never conversations or account credentials. Claude sources are excluded. Improve transient retries and WebSocket message compatibility.
- Fix inherited-prefix accounting for paginated Codex subagents, lingering Claude Desktop estimates after tool-ended runs, and missed macOS updates when quiet sessions resume after midnight.
- Reduce repeated homepage cost calculations and database connection overhead. Strengthen legacy upgrades, interrupted recovery, lock-contention handling, and unknown-version safeguards.

Codex quota queries require a locally installed, signed-in Codex. Claude quota appears only when a valid local cache is available. Requires macOS 14 or newer; the Mac package is for Apple Silicon. Windows x64 and ARM64 packages are provided. The Mac app is ad-hoc signed and not notarized; Windows installers have no commercial code-signing certificate. Automatic updates verify their respective Sparkle and Tauri update signatures.
