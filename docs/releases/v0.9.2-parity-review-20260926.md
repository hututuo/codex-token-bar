# v0.9.2 三端同步复核（2026-09-26）

范围：本轮已报告的金额提示、二级额度侧栏、排行榜翻页、缓存提醒与速率量程，以及相关平台适配和发布版本。源码核对不等同于三端全部交互均已实机验收。

## 实现关系

- macOS 正式发布线：Sources/CodexTokenBar 下的原生 Swift/SwiftUI。
- 跨平台线：tauri-app/src 的 React/TypeScript 与 src-tauri 的 Rust。
- Windows：使用同一套跨平台前端和核心，另有 Windows 原生窗口、裁切、安装器与更新适配；不是第三份独立业务实现。

本轮发现并修复：前端 fallback、快照和侧栏启动值仍分散写死 200；Rust 默认及 sanitizer 仍是 200；Tauri 可调上限为 400 而 Swift 为 500。现统一默认 150、范围 50–500。按用户补充要求，首次运行 v0.9.2 会一次性把升级前已保存的量程也设为 150，此后手动调整继续持久化。

本机状态库结构核对显示 review 来源为 `guardian_review`，普通会话的 `title` 常与 `first_user_message` 相同，而独立的 `name` 才是正式会话名称。仅读取结构和字段关系，没有记录会话正文。抽样最近 80 个 rollout 的结构标记，发现 711 次 `compacted`，其中 709 次后续有 `token_count`；新规则把该首个有效请求作为基线。
