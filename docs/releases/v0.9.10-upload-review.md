# Codex Token Bar v0.9.10

## 简体中文

本次合并升级恢复与压缩用量计账修复，Mac 和 Windows 同步更新。

- 修复部分 0.9.8／0.9.9 用户被正常保留的旧索引副本拦截、无法进入应用的问题，兼容旧版 schema 13 与 14 的接续。
- 保护运行中新建的数据分区，避免晚到旧库将其误判为空并覆盖；完善迁移中断、旧文件或目录被移走后的备份恢复；已接收的旧库不再反复作为活动来源打开。无法安全核验的来源会保留并提示，不通过清空账本绕过。
- 相同输入重试复用已验证的迁移备份，修复重复制造副本；现有旧账、备份和恢复材料继续保留。
- 正确计入可确认的 Codex 压缩请求用量，排除累计快照、继承计数和重复镜像；费用、缓存统计、图表及周期归因同步修正。
- 未报告用量保持为未知；存在缺口的区间保留已知费用小计，避免输出不可靠的整期额度反推或本机／非本机消耗结论。
- 可读取的历史由后台回算；原始会话已删除时仍保留已入账历史，不猜补缺失用量。测速和排行榜上报口径保持独立。

如果旧版提示“账本准备未完成”，请直接覆盖安装 0.9.10。无需先卸载，也不要删除数据目录、旧数据库或迁移清单。

macOS 为 Apple Silicon、ad-hoc 签名且未公证；Windows 提供 x64 和 ARM64 安装包，无商业代码签名。自动更新继续使用原有 Sparkle 与 Tauri 更新签名。

## English

This release combines upgrade recovery and compaction-usage accounting fixes for Mac and Windows.

- Fix startup blocks affecting some 0.9.8/0.9.9 users when valid retained index copies coexist, including the schema 13-to-14 upgrade path.
- Protect namespaces created by running modules from being mistaken for empty import destinations. Improve interrupted migration and verified-backup recovery after old files or directories move. Consumed originals are no longer reopened as active inputs. Sources that cannot be safely verified are preserved with a diagnostic rather than bypassed by clearing history.
- Reuse verified migration backups for unchanged retries instead of generating duplicate copies. Existing accounting history, backups, and recovery evidence remain preserved.
- Account for confirmed Codex compaction requests while excluding cumulative snapshots, inherited counters, and duplicate mirrors. Update costs, cache statistics, charts, and cycle attribution consistently.
- Keep unreported usage unknown. Intervals with gaps retain known cost subtotals without unreliable full-cycle quota estimates or definitive local-versus-other-device attribution.
- Reprocess readable history in the background. Keep recorded history when original sessions are missing, without inventing usage. Speed measurements and leaderboard reporting retain their separate accounting rules.

If an older version reports “Ledger preparation incomplete,” install 0.9.10 over it. Do not uninstall first or delete data directories, old databases, or migration receipts.

The Apple Silicon Mac package is ad-hoc signed and not notarized. Windows x64 and ARM64 installers have no commercial code-signing certificate. Automatic updates retain the existing Sparkle and Tauri signatures.
