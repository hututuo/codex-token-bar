01 — 多种显示方式

不用切回主窗口，
也知道发生了什么。

贴边侧栏、桌面悬浮窗、菜单栏／托盘和主界面。
选你顺手的方式，额度监控始终在同一条流程里。

贴边，留出工作空间

左右停靠、自动吸附、记住位置。悬停看概要，点击查看完整详情。

额度与重置，一起看

按官方实际提供的窗口显示 5h／7d、重置时间和可用储备额度；白线提供均匀使用参考。

悬浮窗，随手摆放

速率、用量、任务和额度自由组合；还可调整内容顺序、配色、字号和透明度。

上方直接渲染跨平台端原组件与原 CSS，保留完整详情和默认悬浮窗内容。用量、额度、会话与 TPS 来自作者本机真实快照，采集时间在画布内标示；窗口位置由离线画布承载。活动速率未持久化，悬浮窗的 0.0 仅为占位。

03 — 低缓存命中提醒

额度突然跑得快？
先看这次缓存。

换了模型、思考强度或上下文后，如果本次请求的缓存复用偏低，侧栏会主动提醒。

看一眼命中率和相关会话，再决定是否检查刚才的操作。不用等到额度快用完，才发现不对劲。

实际 token 用量触发可关闭关联会话
这些变化是可能的排查方向，不能仅凭低命中确定原因。提醒不按“等了多久”判断缓存失效。

切换强度 → 开启 Fast → 发送消息 → 低命中提醒。
Codex 界面为模拟，Bar 提醒为原生渲染；场景与数据均为演示。

04 — 模型速度

现在在忙什么，
哪个模型输出更快。

实时活动曲线帮你看进度，正文 TPS 帮你比较速度。
各模型最新读数、近 15／30 分钟均速，以及每条样本的来处，都能查。

实时活动速率看此刻的工作节奏

汇总多个会话的本地活动估算；识别到中断时停止，正常完成后最多收尾 5 秒。

正文 TPS看可追溯的输出样本

本地正文分词量 ÷ 日志起止时长；包含中间消息和最终文本。低质量样本保留说明，不纳入均速。

此处为作者本机采集到的真实正文样本，均速截至快照时刻。正文 TPS 不是服务器纯生成速度，计时可能包含网络等待；隐藏思考和工具返回不作为正文测速样本。

05 — 完整工作台

展开主界面，
还有这些顺手的工具。

从看一眼状态，到回看数据、整理会话，
日常需要的信息和管理入口放在一起。

01

任务与子 Agent

查看运行中的主会话和子代理、模型及思考强度，接收完成与未读反馈。

02

缓存排行

按会话或单轮查命中率、命中与未命中 token；搜索、筛选，追到具体上下文。

03

重置卡与双雷达

查看接口提供的重置卡数量、来源和到期信息；官方 Radar 与众测排行提供额外参考。

04

会话管理

搜索、归档、恢复归档，创建、校验和导出恢复包；删除前核对影响范围并备份。

05

独立 Codex 实例

创建或登记独立数据目录的实例，管理启动、停止、配置与会话同步。

06

自动续跑与会话增强

按指定时间、额度恢复或特定失败条件续跑；还有 Markdown 导出、项目移动和阅读体验设置。

展开完整功能与数据口径

本地统计：输入、缓存、输出、调用、模型占比和费用估算；已建立的历史账本不会随源会话删除而清空。压缩与未压缩历史使用同一统计身份。

官方额度：通过本机 Codex app-server 读取当前登录账号，由 Codex 处理网络请求和鉴权。只展示接口实际提供的窗口；重置卡仅展示，不自动兑换。

缓存提醒：输入至少 2 万 token、单次命中率低于 30% 时提醒；新上下文首次请求豁免。续问时限建议与旧缓存间隔扫描仍停用。

正文 TPS：已完成正文使用本地 o200k_base 分词器；时长不超过 0.55 秒、计时不一致及异常速率等样本不参与均速。可在应用详情中定位会话、轮次和正文 ID。

自动续跑：默认关闭；先选择精确会话，支持冷却与每日次数限制。“自动批准普通操作”为独立选项，危险操作、额外权限和人工输入仍拦截。

会话增强：Markdown 导出、项目移动、ID、粘贴修复、阅读宽度、滚动位置恢复。旧 Codex 侧栏直接删除入口已停用。
