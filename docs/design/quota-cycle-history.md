# 实际额度周期历史

## 用户目标

从主界面模型用量区域翻阅本期、上一期和历史周期，查看各周期的本机 Token、调用和模型 API 等值。重置卡或强制重置可能提前结束一期，因此不得固定切成七天。

## 边界证据

- 复用永久保存的额度观测，不迁移数据库，不新增采集器。
- 周期按 Codex Home、稳定账号、套餐和额度类型隔离。现有 cycle generation 只作候选，不直接冒充上游周期 ID。
- 额度重置时间轻微抖动或单独校正不拆期。提前结束需要额度已用下降、重置时间显著推进、后续新鲜观测确认，并通过现有异常过滤。
- 没有精确重置事件时，只能给出旧周期末次观测与新周期首次观测之间的边界区间，不能伪造秒级起止。
- 首期起点未知时显示已观测部分。长离线不补造未观测周期，也不把旧周期终点直接当当前期起点。

## 用量口径

- 查询现有精确 SQLite 索引和已发布聚合，按需加载所选范围；不得为翻页重扫 JSONL。
- 确定内部用量与不确定边界区间单列，不能重计。沿用现有模型识别、缓存组成和价格口径；未知价格保持未知。
- 精确用量事件没有账号归属字段。因此统一注明“本机记录 · 账号归属未核验”，不称账号全量账单。
- 切 Home、切账号或数据代次变化时，旧异步响应不得覆盖当前选期结果。

## 界面

费用区提供“本期 / 上一期 / 周期列表”。显示实际起止或观测区间，以及“起点未知”“提前结束”“边界待确认”等简短标签。详细证据说明放在帮助或展开区域，避免在常规界面展示数据库实现细节。
