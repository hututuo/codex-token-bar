# 模型配色调整

本图是默认色表的深浅底配色预览，不是运行数据或正式应用截图。

| 模型 | 默认色 |
|---|---|
| Astra | 淡绿 `#A3D977` |
| 6.1 Sol | 橙红 `#DF7055` |
| 6 Luna | 天蓝 `#63A6EB` |
| 6 Sol | 金色 `#D6AC5B`，与 6 Luna 区分 |
| Claude Opus | 柔紫 `#B89ADD` |
| Claude Sonnet | 暖杏 `#DCA16C` |
| Claude Haiku | 青绿 `#5CBCAF` |

5.6 Sol/Terra/Luna 改为更收敛的灰紫、紫、灰蓝。品牌色与模型色分开：客户端额度标识仍沿用客户端配色设置。

修改原有 Swift `ModelUsagePresentation`、TypeScript `modelUsagePresentation`，用量、模型贡献速度条、趋势和列表复用同一入口。Claude 按家族分配，兼容日期后缀、大小写、下划线、Anthropic/Bedrock 包装名；只改变呈现颜色，不归并模型 ID、版本、费用账本或统计分组。未知模型继续使用稳定兜底色。

两端色表一致性、混合速度条占比、Claude 包装名和模型身份保留有测试。`palette-preview.png` 直接根据 Swift 色表生成。
