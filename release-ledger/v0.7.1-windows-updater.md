## Key Handling

The earlier Tauri updater private key was encrypted with an unknown password and
could not be used for non-interactive release signing. It was backed up under:

- `runs/20260702-2010_windows-v0.7.1-release/key-backup/`

A new local Tauri updater key was generated at:

- Private key: `/Users/huyiyang/.config/codex-token-bar/tauri-updater.key`
- Public key: `/Users/huyiyang/.config/codex-token-bar/tauri-updater.key.pub`

The new public key is embedded in `tauri-app/src-tauri/tauri.conf.json`.
The private key is outside the repository and must not be committed or copied to
Windows build machines. For this key, Tauri CLI signing in non-interactive shells
requires explicitly passing an empty password, for example `--password ''`.
