## Source Baseline

This candidate includes both bounded-history-memory repairs:

- Swift native scanner: `14ccc58`.
- Tauri/Rust scanner and cache: `1903256`.

The Tauri repair places hard limits on session bytes, JSONL line size, event counts, cache shard bytes/counts, per-session fingerprints, and directory file counts. It rejects changed files and malformed or over-limit scans rather than presenting a partial precise total. Oversized input falls back to safe metadata instead of retaining unbounded history in memory.
