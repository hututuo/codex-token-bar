## Publication Procedure

Target repository: `hututuo/codex-token-bar`.
Release body: `release-notes/v0.7.2.md` (Simplified Chinese first, English second).

The following reviewed procedure was executed after explicit user authorization.

### 1. Pushed reviewed branch and created the single tag

```bash
git push origin release/v0.7.2
RELEASE_COMMIT="$(git rev-parse release/v0.7.2)"
git tag -a v0.7.2 "$RELEASE_COMMIT" -m "Codex Token Bar v0.7.2"
git push origin v0.7.2
```

### 2. Created a draft release with every platform asset

```bash
gh release create v0.7.2 \
  --repo hututuo/codex-token-bar \
  --draft \
  --title "Codex Token Bar v0.7.2" \
  --notes-file release-notes/v0.7.2.md \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-macos-arm64.dmg \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-macos-arm64.app.zip \
  dist/release/v0.7.2/CodexTokenBar.app.zip \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-windows-x64-setup.exe \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-windows-x64-setup.exe.sig \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-windows-arm64-setup.exe \
  dist/release/v0.7.2/CodexTokenBar-v0.7.2-windows-arm64-setup.exe.sig \
  dist/release/v0.7.2/latest-windows.json \
  dist/release/v0.7.2/SHA256SUMS-v0.7.2.txt
```

The draft asset names, sizes, SHA256 values, release notes, and download URLs were reviewed before publication.

### 3. Published the GitHub Release, then the update metadata

```bash
gh release edit v0.7.2 --repo hututuo/codex-token-bar --draft=false --latest

git switch main
git pull --ff-only origin main
git merge --ff-only release/v0.7.2
git push origin main
```

The draft was published first so the Windows installers, signatures, and `latest-windows.json` became available atomically. Remote `main` was then fast-forwarded to the reviewed release commit, publishing the matching Sparkle `appcast.xml`.

### 4. Final remote verification

```bash

curl -fL https://raw.githubusercontent.com/hututuo/codex-token-bar/main/appcast.xml
curl -fL https://github.com/hututuo/codex-token-bar/releases/download/v0.7.2/latest-windows.json
```

Remote verification also re-downloaded and hashed all assets, verified the Sparkle enclosure URL/length/signature, verified both Windows updater signatures, and confirmed the release is marked latest.
