## Windows ARM64 Build

Current status: blocked.

What is ready:

- Rust target `aarch64-pc-windows-msvc` was installed on the Windows x64 build host after manually supplying the matching `rust-std` package.
- The project build script now prefers `%USERPROFILE%\.cargo\bin` so Rustup's sysroot is used instead of an incompatible standalone Program Files Rust sysroot.

Current blocker:

- The x64 Windows host still lacks a working Visual Studio C++ ARM64 compiler/runtime setup. `Hostx64\arm64\cl.exe` and ARM64 MSVC runtime libraries were not found after VS Build Tools modification attempts.
- After VS installer attempts, SSH to `192.168.123.44` reaches port 22 but closes before SSH key exchange, so automated build/asset retrieval cannot continue through SSH.
- The local Parallels ARM Windows VM starts briefly but returns to `paused` and has no visible IP, so it is not yet usable for ARM64 packaging.

Next build steps after a working Windows remote channel is restored:

3. Copy both Windows installers and `SHA256SUMS-v0.7.0-windows.txt` back to `dist/release/v0.7.0/windows/`.
